# Argo CD & GitOps - Complete Beginner's Guide

> **Status:** Under Active Development 🚧  
> This guide is part of the **Complete Beginner's Guide to All Tools** series.

## Overview

Argo CD is a declarative, GitOps continuous delivery tool for Kubernetes. GitOps uses Git repositories as the single source of truth for defining infrastructure and application configurations.
