# Security & DevSecOps - Complete Beginner's Guide

> **Status:** Under Active Development 🚧  
> This guide is part of the **Complete Beginner's Guide to All Tools** series.

## Overview

DevSecOps integrates security practices into the DevOps delivery pipeline. Instead of security being an isolated stage at the end of development, security is applied at every phase—from code scanning and dependencies to cloud infrastructure and container runtime defense.

## Planned Curriculum

- **Part 1:** DevSecOps Foundations: Shifting Security Left in Modern Software Delivery
- **Part 2:** Secure Coding Practices and Secret Scanning (TruffleHog, Gitleaks)
- **Part 3:** Static Application Security Testing (SAST) in CI/CD (SonarQube, Semgrep)
- **Part 4:** Software Composition Analysis (SCA) and Vulnerability Management (Trivy, Snyk)
- **Part 5:** Container Security and Base Image Hardening
- **Part 6:** Infrastructure as Code Security: Checkov, tfsec, and Policy as Code (OPA / Kyverno)
- **Part 7:** Cloud Security Posture Management & IAM Least Privilege
- **Part 8:** Kubernetes Security: Pod Security Standards, Network Policies, and RBAC
- **Part 9:** Dynamic Application Security Testing (DAST) and API Security (OWASP ZAP)
- **Part 10:** Production DevSecOps Project: Automated Security Gate Pipeline
