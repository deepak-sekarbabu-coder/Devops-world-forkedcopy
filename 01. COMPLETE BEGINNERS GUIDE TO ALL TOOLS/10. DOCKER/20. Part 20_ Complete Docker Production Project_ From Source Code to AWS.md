# 1. What You Are Building

The project is a small three-tier application.

It contains:

```text
Web
↓
API
↓
PostgreSQL
```

The Web container accepts user traffic.

The API container contains application logic.

PostgreSQL stores persistent application data.

Locally:

```text
Browser
↓
Web Container
↓
API Container
↓
PostgreSQL Container
↓
Docker Volume
```

In the AWS learning deployment:

```text
Internet
↓
Application Load Balancer
↓
EC2
↓
Docker
↓
Web Container
↓
API Container
↓
PostgreSQL Container
↓
Persistent Docker Volume
```

For a more mature production system, the database would often be moved to a managed database service such as Amazon RDS rather than being operated inside the same EC2 Docker host.

We intentionally begin with PostgreSQL in Docker because this project is designed to prove that you understand Docker storage, networking, Compose, containers, health checks, and recovery.

# 18. API Source

Create:

```text
api/app.py
```

```python
import os
import time

import psycopg
from flask import Flask, jsonify, request

app = Flask(__name__)


def database_config():
    required = [
        "DB_HOST",
        "DB_PORT",
        "DB_NAME",
        "DB_USER",
        "DB_PASSWORD",
    ]

    missing = [name for name in required if not os.getenv(name)]

    if missing:
        raise RuntimeError(
            f"Missing required environment variables: {', '.join(missing)}"
        )

    return {
        "host": os.environ["DB_HOST"],
        "port": os.environ["DB_PORT"],
        "dbname": os.environ["DB_NAME"],
        "user": os.environ["DB_USER"],
        "password": os.environ["DB_PASSWORD"],
    }


def get_connection():
    return psycopg.connect(**database_config())


def initialize_database(retries=20, delay=2):
    last_error = None

    for attempt in range(1, retries + 1):
        try:
            with get_connection() as conn:
                with conn.cursor() as cur:
                    cur.execute(
                        """
                        CREATE TABLE IF NOT EXISTS tasks (
                            id SERIAL PRIMARY KEY,
                            title TEXT NOT NULL,
                            created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
                        )
                        """
                    )
                conn.commit()

            print("database initialized", flush=True)
            return

        except Exception as exc:
            last_error = exc
            print(
                f"database unavailable attempt={attempt}/{retries} error={exc}",
                flush=True,
            )
            time.sleep(delay)

    raise RuntimeError(
        f"database unavailable after {retries} attempts"
    ) from last_error


@app.get("/health")
def health():
    try:
        with get_connection() as conn:
            with conn.cursor() as cur:
                cur.execute("SELECT 1")
                cur.fetchone()

        return jsonify(
            status="healthy",
            database="reachable",
        ), 200

    except Exception as exc:
        app.logger.error("health check failed: %s", exc)

        return jsonify(
            status="unhealthy",
            database="unreachable",
        ), 503


@app.get("/tasks")
def list_tasks():
    with get_connection() as conn:
        with conn.cursor() as cur:
            cur.execute(
                """
                SELECT id, title, created_at
                FROM tasks
                ORDER BY id
                """
            )

            rows = cur.fetchall()

    return jsonify(
        [
            {
                "id": row[0],
                "title": row[1],
                "created_at": row[2].isoformat(),
            }
            for row in rows
        ]
    )


@app.post("/tasks")
def create_task():
    payload = request.get_json(silent=True) or {}
    title = str(payload.get("title", "")).strip()

    if not title:
        return jsonify(error="title is required"), 400

    with get_connection() as conn:
        with conn.cursor() as cur:
            cur.execute(
                """
                INSERT INTO tasks (title)
                VALUES (%s)
                RETURNING id, title, created_at
                """,
                (title,),
            )

            row = cur.fetchone()

        conn.commit()

    return jsonify(
        id=row[0],
        title=row[1],
        created_at=row[2].isoformat(),
    ), 201


if __name__ == "__main__":
    initialize_database()
    app.run(
        host="0.0.0.0",
        port=5000,
    )
```

# 23. API Multi-Stage Dockerfile

Create:

```text
api/Dockerfile
```

```dockerfile
FROM python:3.13-slim AS builder

WORKDIR /build

COPY requirements.txt .

RUN pip install \
    --no-cache-dir \
    --prefix=/install \
    -r requirements.txt


FROM python:3.13-slim AS runtime

ENV PYTHONDONTWRITEBYTECODE=1
ENV PYTHONUNBUFFERED=1

WORKDIR /app

COPY --from=builder /install /usr/local

COPY --chown=10001:10001 app.py .

USER 10001:10001

EXPOSE 5000

CMD [
  "gunicorn",
  "--bind=0.0.0.0:5000",
  "--workers=2",
  "--access-logfile=-",
  "--error-logfile=-",
  "--timeout=30",
  "app:app"
]
```

Before publishing or deploying long-term, verify and deliberately pin the tested base-image version or digest according to your release policy.

```nginx
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
```

```yaml
      retries: 5

      - frontend
      - backend

  db:
    image: postgres:17
    environment:
      POSTGRES_DB: ${POSTGRES_DB}

      - postgres-data:/var/lib/postgresql/data

      test:
        - CMD-SHELL
        - pg_isready -U "$${POSTGRES_USER}" -d "$${POSTGRES_DB}"

  backend:
    internal: true
```

# 64. Public vs Private

A subnet is considered public when its associated route table has a route to an Internet Gateway.

Conceptually:

```text

0.0.0.0/0
↓

```

A private application subnet does not route internet-bound traffic directly through an Internet Gateway.

# 65. Important Private-Subnet Problem

If EC2 has no direct internet path, it still may need outbound access for:


Options can include:

```text

VPC endpoints
other controlled egress architecture
```

Do not put an instance into a private subnet and then assume it can reach ECR or package repositories.

# 96. GitHub Actions Workflow

Use a workflow similar to:

```yaml
name: Docker CI/CD

on:
  push:
    branches:
      - main

permissions:
  contents: read
  id-token: write

env:
  AWS_REGION: us-east-1
  API_REPOSITORY: veriqta-api
  WEB_REPOSITORY: veriqta-web

jobs:

  test-build-scan-push:
    runs-on: ubuntu-latest

    steps:

      - name: Checkout repository
        uses: actions/checkout@v6

      - name: Set up Python
        uses: actions/setup-python@v6
        with:
          python-version: "3.13"

      - name: Install test dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r api/requirements-dev.txt

      - name: Run unit tests
        run: |
          pytest api/test_app.py

      - name: Build API image
        run: |
          docker build \
            -t veriqta-api:${GITHUB_SHA} \
            ./api

      - name: Build Web image
        run: |
          docker build \
            -t veriqta-web:${GITHUB_SHA} \
            ./web

      - name: Scan API image
        uses: aquasecurity/trivy-action@master
        with:
          image-ref: veriqta-api:${{ github.sha }}
          severity: CRITICAL,HIGH
          exit-code: "1"

      - name: Scan Web image
        uses: aquasecurity/trivy-action@master
        with:
          image-ref: veriqta-web:${{ github.sha }}
          severity: CRITICAL,HIGH
          exit-code: "1"

      - name: Configure AWS credentials
        uses: aws-actions/configure-aws-credentials@v6
        with:
          role-to-assume: ${{ secrets.AWS_ROLE_ARN }}
          aws-region: ${{ env.AWS_REGION }}

      - name: Login to Amazon ECR
        id: login-ecr
        uses: aws-actions/amazon-ecr-login@v2

      - name: Tag and push API
        env:
          REGISTRY: ${{ steps.login-ecr.outputs.registry }}
        run: |
          docker tag \
            veriqta-api:${GITHUB_SHA} \
            ${REGISTRY}/${API_REPOSITORY}:${GITHUB_SHA}

          docker push \
            ${REGISTRY}/${API_REPOSITORY}:${GITHUB_SHA}

      - name: Tag and push Web
        env:
          REGISTRY: ${{ steps.login-ecr.outputs.registry }}
        run: |
          docker tag \
            veriqta-web:${GITHUB_SHA} \
            ${REGISTRY}/${WEB_REPOSITORY}:${GITHUB_SHA}

          docker push \
            ${REGISTRY}/${WEB_REPOSITORY}:${GITHUB_SHA}
```

Before production use, pin third-party GitHub Actions to reviewed commit SHAs according to your supply-chain policy rather than automatically trusting mutable references.

# 136. Rollback Script

Create:

```text
scripts/rollback.sh
```

```bash
#!/usr/bin/env bash

set -Eeuo pipefail

if [ "$#" -ne 1 ]; then
    echo "Usage: $0 <previous-image-tag>"
    exit 1
fi

previous_tag="$1"

export IMAGE_TAG="$previous_tag"

echo "Rolling back to ${IMAGE_TAG}"

./scripts/deploy.sh

./scripts/verify.sh

echo "Rollback completed"
```
