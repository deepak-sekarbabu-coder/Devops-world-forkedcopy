# Project 2: S3 Inventory and Governance Automation

## Real-World Scenario

The organization has been using Amazon S3 for several years.

Different teams have created buckets for:

* application assets
* CI/CD artifacts
* Terraform state
* centralized logs
* backups
* database exports
* static websites
* analytics datasets
* temporary file transfers
* deployment packages
* security logs
* archived data

The environment started with a handful of buckets.

Now there are dozens or hundreds.

Nobody wants to open every bucket manually and inspect:

```text
Properties
Permissions
Management
Encryption
Versioning
Logging
Lifecycle
Tags
Object Ownership
Public Access Block
Bucket Policy
```

The DevOps team receives a request:

"Produce an inventory of every S3 bucket. Show where it is located, when it was created, whether versioning is enabled, whether encryption is configured, whether public access protections are enabled, whether the bucket has a policy, whether required tags exist, whether lifecycle management is configured, whether logging is enabled, and what Object Ownership configuration it uses. Clearly distinguish configuration failures from resources the automation could not inspect."

That final sentence is extremely important.

Suppose our automation checks encryption and receives:

```text
AccessDenied
```

We cannot truthfully report:

```text
Encryption: DISABLED
```

We do not know.

The correct result is:

```text
Encryption: ACCESS_DENIED
```

This project therefore introduces a major production automation principle:

```text
FAIL
≠
ACCESS_DENIED
```

A failed governance control means:

```text
We inspected the configuration,
and it did not meet the rule.
```

Access denied means:

```text
We could not obtain enough evidence
to evaluate the rule.
```

Those are completely different findings.

# Part 3: Define the Status Model

We will use four classifications.

## PASS

The configuration was inspected and satisfies our rule.

Example:

```text
Encryption:
AES256

Status:
PASS
```

## FAIL

We successfully inspected the resource and confirmed that it does not meet a required control.

Example:

```text
Required Public Access Block:
Not fully enabled

Status:
FAIL
```

## REVIEW

The configuration is not necessarily incorrect, but a human should review it.

Example:

```text
Server Access Logging:
Disabled

Status:
REVIEW
```

Why REVIEW instead of automatically FAIL?

Because not every organization requires server access logging on every bucket. Some may use CloudTrail data events, centralized access patterns, or other controls.

## ACCESS_DENIED

The automation could not retrieve enough evidence.

Example:

```text
GetBucketEncryption:
AccessDenied

Status:
ACCESS_DENIED
```

This must never silently become FAIL.


# Part 9: Determine Bucket Region

S3 is globally addressable, but buckets belong to AWS regions.

Create:

```python
def get_bucket_region(
    s3_client,
    bucket_name
):
    response = (
        s3_client.get_bucket_location(
            Bucket=bucket_name
        )
    )

    location = response.get(
        "LocationConstraint"
    )

    if location is None:
        return "us-east-1"

    if location == "EU":
        return "eu-west-1"

    return location
```

This normalization is useful because historical S3 API behavior can represent certain regions differently.

# Part 14: Inspect Versioning

Create:

```python
def inspect_versioning(
    s3_client,
    bucket_name
):
    try:
        response = (
            s3_client.get_bucket_versioning(
                Bucket=bucket_name
            )
        )

        status = response.get(
            "Status"
        )

        if status == "Enabled":
            return result(
                "PASS",
                value="Enabled"
            )

        if status == "Suspended":
            return result(
                "REVIEW",
                value="Suspended",
                message=(
                    "Bucket versioning "
                    "is suspended."
                )
            )

        return result(
            "REVIEW",
            value="Not enabled",
            message=(
                "Bucket versioning "
                "is not enabled."
            )
        )

    except ClientError as error:
        code, message = (
            get_error_details(
                error
            )
        )

        if code in ACCESS_DENIED_CODES:
            return result(
                "ACCESS_DENIED",
                message=message
            )

        raise
```

# Part 16: Inspect Server-Side Encryption

Create:

```python
def inspect_encryption(
    s3_client,
    bucket_name
):
    try:
        response = (
            s3_client
            .get_bucket_encryption(
                Bucket=bucket_name
            )
        )

        rules = (
            response.get(
                "ServerSideEncryptionConfiguration",
                {}
            ).get(
                "Rules",
                []
            )
        )

        algorithms = []

        for rule in rules:
            default_encryption = (
                rule.get(
                    "ApplyServerSideEncryptionByDefault",
                    {}
                )
            )

            algorithm = (
                default_encryption.get(
                    "SSEAlgorithm"
                )
            )

            if algorithm:
                algorithms.append(
                    algorithm
                )

        if algorithms:
            return result(
                "PASS",
                value=algorithms
            )

        return result(
            "FAIL",
            value=[],
            message=(
                "No usable encryption "
                "rule was returned."
            )
        )

    except ClientError as error:
        code, message = (
            get_error_details(
                error
            )
        )

        if code in ACCESS_DENIED_CODES:
            return result(
                "ACCESS_DENIED",
                message=message
            )

        if code in {
            "ServerSideEncryptionConfigurationNotFoundError",
            "NoSuchConfiguration"
        }:
            return result(
                "FAIL",
                value=None,
                message=(
                    "No bucket encryption "
                    "configuration was found."
                )
            )

        raise
```

---

# Part 17: Important Encryption Nuance

Students must understand something important.

Modern S3 automatically encrypts new objects at rest by default.

Therefore, the phrase:

```text
unencrypted S3 bucket
```

can be misleading in a modern AWS environment.

Our lab check is specifically evaluating the bucket encryption configuration returned through the S3 API and whether it satisfies our defined governance policy.

Do not confuse:

```text
No explicit configuration discovered
```

with:

```text
AWS stores every object in plaintext.
```

Those are not equivalent statements.

This is exactly why production automation requires precise wording.

# Part 19: Inspect Public Access Block

S3 Public Access Block has multiple controls.

Create:

```python
def inspect_public_access_block(
    s3_client,
    bucket_name
):
    try:
        response = (
            s3_client
            .get_public_access_block(
                Bucket=bucket_name
            )
        )

        config = response.get(
            "PublicAccessBlockConfiguration",
            {}
        )

        required = {
            "BlockPublicAcls": True,
            "IgnorePublicAcls": True,
            "BlockPublicPolicy": True,
            "RestrictPublicBuckets": True
        }

        compliant = all(
            config.get(key) is value
            for key, value
            in required.items()
        )

        if compliant:
            return result(
                "PASS",
                value=config
            )

        return result(
            "FAIL",
            value=config,
            message=(
                "Not all bucket-level "
                "Public Access Block "
                "settings are enabled."
            )
        )

    except ClientError as error:
        code, message = (
            get_error_details(
                error
            )
        )

        if code in ACCESS_DENIED_CODES:
            return result(
                "ACCESS_DENIED",
                message=message
            )

        if code in {
            "NoSuchPublicAccessBlockConfiguration"
        }:
            return result(
                "FAIL",
                value=None,
                message=(
                    "Bucket-level Public "
                    "Access Block configuration "
                    "was not found."
                )
            )

        raise
```

# Part 23: Inspect Bucket Tags

Create:

```python
def inspect_tags(
    s3_client,
    bucket_name,
    required_tags
):
    try:
        response = (
            s3_client.get_bucket_tagging(
                Bucket=bucket_name
            )
        )

        tag_set = response.get(
            "TagSet",
            []
        )

        tags = {
            tag.get("Key"): (
                tag.get("Value", "")
            )
            for tag in tag_set
            if tag.get("Key")
        }

        missing = [
            tag
            for tag in required_tags
            if not tags.get(tag)
        ]

        if missing:
            return result(
                "FAIL",
                value={
                    "tags": tags,
                    "missing": missing
                },
                message=(
                    "Required tags "
                    "are missing."
                )
            )

        return result(
            "PASS",
            value={
                "tags": tags,
                "missing": []
            }
        )

    except ClientError as error:
        code, message = (
            get_error_details(
                error
            )
        )

        if code in ACCESS_DENIED_CODES:
            return result(
                "ACCESS_DENIED",
                message=message
            )

        if code == "NoSuchTagSet":
            return result(
                "FAIL",
                value={
                    "tags": {},
                    "missing": list(
                        required_tags
                    )
                },
                message=(
                    "Bucket has no "
                    "tag set."
                )
            )

        raise
```

```python
def inspect_ownership(

    bucket_name
):

            .get_bucket_ownership_controls(

            get_error_details(
                error
            )
        )

        if code in ACCESS_DENIED_CODES:
            return result(
                "ACCESS_DENIED",
                message=message
            )

        if code in {
            "OwnershipControlsNotFoundError",
            "NoSuchOwnershipControls"
        }:
            return result(
                "REVIEW",
                value=None,
                message=(
                    "No explicit Object "
                    "Ownership controls "
                    "were returned."
                )
            )

        raise
```

# Part 32: Build a Safe Inspection Wrapper

We do not want one unexpected API failure to terminate inspection of every bucket.

Create:

```python
def safe_inspection(
    check_name,
    inspection_function,
    logger,
    bucket_name
):
    try:
        return inspection_function()

    except ClientError as error:
        code, message = (
            get_error_details(
                error
            )
        )

        logger.error(
            "S3 inspection failed "
            "bucket=%s check=%s "
            "code=%s message=%s",
            bucket_name,
            check_name,
            code,
            message
        )

        if code in ACCESS_DENIED_CODES:
            return result(
                "ACCESS_DENIED",
                message=message
            )

        return result(
            "REVIEW",
            message=(
                f"Inspection error: "
                f"{code}: {message}"
            )
        )

    except BotoCoreError as error:
        logger.error(
            "S3 SDK failure "
            "bucket=%s check=%s "
            "error=%s",
            bucket_name,
            check_name,
            error
        )

        return result(
            "REVIEW",
            message=(
                f"SDK inspection "
                f"failure: {error}"
            )
        )

    except Exception as error:
        logger.exception(
            "Unexpected S3 inspection "
            "failure bucket=%s "
            "check=%s",
            bucket_name,
            check_name
        )

        return result(
            "REVIEW",
            message=(
                f"Unexpected inspection "
                f"failure: {error}"
            )
        )
```

# Part 35: Determine Overall Bucket Status

We need a consistent rule.

Create:

```python
STATUS_PRIORITY = {
    "PASS": 0,
    "REVIEW": 1,
    "FAIL": 2,
    "ACCESS_DENIED": 3
}
```

But overall status requires careful thinking.

If one required check fails and another is inaccessible, should overall status be FAIL or ACCESS_DENIED?

A useful model is:

```text
ACCESS_DENIED
```

when incomplete evidence prevents a complete assessment.

However, we should still preserve confirmed failures.

Therefore, do not rely only on one overall status.

Keep:

```text
overall_status
confirmed_failures
access_denied_checks
review_checks
```

Create:

```python
def classify_bucket(
    bucket_record
):
    control_names = [
        "versioning",
        "encryption",
        "public_access_block",
        "bucket_policy",
        "tags",
        "lifecycle",
        "logging",
        "object_ownership"
    ]

    statuses = {
        control: (
            bucket_record.get(
                control,
                {}
            ).get(
                "status",
                "REVIEW"
            )
        )
        for control in control_names
    }

    confirmed_failures = [
        name
        for name, status
        in statuses.items()
        if status == "FAIL"
    ]

    denied = [
        name
        for name, status
        in statuses.items()
        if status == "ACCESS_DENIED"
    ]

    reviews = [
        name
        for name, status
        in statuses.items()
        if status == "REVIEW"
    ]

    if denied:
        overall = "ACCESS_DENIED"

    elif confirmed_failures:
        overall = "FAIL"

    elif reviews:
        overall = "REVIEW"

    else:
        overall = "PASS"

    return {
        "overall_status": overall,
        "confirmed_failures": (
            confirmed_failures
        ),
        "access_denied_checks": denied,
        "review_checks": reviews
    }
```

```text
Report
```

Most importantly, it understands the difference between:

```text
PASS
```

The evidence satisfies the control.

```text
REVIEW
```

The configuration requires human or policy-specific review.

```text
FAIL
```

The automation successfully inspected the configuration and confirmed that it violates the defined control.

```text
ACCESS_DENIED
```

The automation could not obtain sufficient evidence to make the decision.

That distinction is not just good Python.

It is good DevOps, security, governance, and production engineering.
