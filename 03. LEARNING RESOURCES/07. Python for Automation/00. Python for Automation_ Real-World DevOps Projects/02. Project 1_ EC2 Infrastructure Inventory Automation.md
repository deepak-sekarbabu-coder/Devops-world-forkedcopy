# Project 1: EC2 Infrastructure Inventory Automation

## Real-World Scenario

The infrastructure team manages Amazon EC2 instances across several AWS regions.

At first, engineers could open the AWS Management Console whenever they needed to answer questions such as:

* How many EC2 instances do we have?
* Which regions contain instances?
* Which instances are running?
* Which instances are stopped?
* Which instances have public IP addresses?
* Which VPC contains a particular instance?
* Which security groups are attached?
* Which AMI launched the instance?
* Does the instance have an IAM instance profile?
* How old is the instance?
* Which instances have been sitting stopped for weeks?
* Which instances do not have meaningful Name tags?

That process does not scale.

Imagine receiving this request:

"Send me an inventory of every EC2 instance in our AWS account, across every enabled region. Include the instance name, state, IP addresses, VPC, subnet, security groups, AMI, IAM profile, launch time, age, and tags. Highlight stopped instances."

Opening every AWS region manually and copying information into a spreadsheet is not a reasonable operational process.

We will automate it.

By the end of this project, we will have a multi-region EC2 inventory system that follows this workflow:

```text
AWS Account
     |
     v
Discover Regions
     |
     v
Connect to Each Region
     |
     v
Describe EC2 Instances
     |
     v
Handle Pagination
     |
     v
Normalize Instance Data
     |
     +--------> Running Instances
     |
     +--------> Stopped Instances
     |
     +--------> Other States
     |
     v
Calculate Instance Age
     |
     v
Generate Operational Summary
     |
     +--------> JSON
     |
     +--------> CSV
     |
     +--------> Logs
```

The final inventory will show:

```text
Region
  ↓
Instance
  ↓
State
  ↓
Network
  ↓
Security Groups
  ↓
AMI
  ↓
IAM Profile
  ↓
Tags
  ↓
Launch Time
  ↓
Instance Age
```

# Part 3: Required IAM Permissions

The script needs permission to inspect EC2 resources.

For the core inventory, the important EC2 actions are:

```text
ec2:DescribeInstances
ec2:DescribeRegions
```

A minimal learning policy might resemble:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ec2:DescribeInstances",
        "ec2:DescribeRegions"
      ],
      "Resource": "*"
    }
  ]
}
```

Do not solve read-only inventory problems by automatically giving scripts:

```text
AdministratorAccess
```

The principle should be:

```text
Required operation
      ↓
Required API
      ↓
Required IAM permission
      ↓
Least privilege
```

# Part 9: Use describe_instances()

The fundamental API call is:

```python
response = ec2.describe_instances()
```

The response is not simply:

```python
[
    instance1,
    instance2
]
```

AWS returns a nested structure.

A simplified response looks like:

```python
{
    "Reservations": [
        {
            "ReservationId": "r-example",
            "Instances": [
                {
                    "InstanceId": "i-example",
                    "InstanceType": "t3.micro"
                }
            ]
        }
    ]
}
```

AWS officially returns instance information inside Reservations.

Therefore the common iteration pattern is:

```python
for reservation in response.get("Reservations", []):
    for instance in reservation.get("Instances", []):
        print(instance["InstanceId"])
```

# Part 10: Understand Reservations and Instances

Students frequently become confused by this structure.

Think of it as:

```text
DescribeInstances Response
        |
        v
Reservations
        |
        +-- Reservation 1
        |      |
        |      +-- Instance A
        |      +-- Instance B
        |
        +-- Reservation 2
               |
               +-- Instance C
```

Your operational inventory usually cares about:

```text
Instances
```

not the reservation itself.

Therefore we flatten the response.

```python
def tags_to_dict(tags):
```


# Part 16: Understand EC2 State Operationally

A useful inventory should not simply display the state.

The engineer should understand it.

## pending

The instance is moving toward running.

## running

The instance is active.

## stopping

The instance is transitioning toward stopped.

## stopped

The instance is shut down but still exists.

AWS does not charge instance usage while a normal instance is stopped, but related resources such as EBS storage may still incur charges.

## shutting-down

Termination is in progress.

## terminated

The instance has been permanently terminated.

AWS notes that recently terminated instances can remain visible in `DescribeInstances` results for a short period, usually less than one hour.

That means our script must not assume:

```text
returned by API = active resource
```

We must inspect the state.

# Part 23: Collect Security Groups

Security groups are returned as a list.

Example:

```python
[
    {
        "GroupId": "sg-0123456789",
        "GroupName": "veriqta-api-prod"
    },
    {
        "GroupId": "sg-9876543210",
        "GroupName": "veriqta-monitoring"
    }
]
```

Convert them into something useful for a report.

Create:

```python
def format_security_groups(groups):
    if not groups:
        return []

    return [
        {
            "id": group.get(
                "GroupId",
                "Unknown"
            ),
            "name": group.get(
                "GroupName",
                "Unknown"
            )
        }
        for group in groups
    ]
```

For CSV, nested structures are less convenient.

Create:

```python
def flatten_security_groups(groups):
    if not groups:
        return ""

    return "; ".join(
        f"{group.get('GroupName', 'Unknown')} "
        f"({group.get('GroupId', 'Unknown')})"
        for group in groups
    )
```

Example:

```text
veriqta-api-prod (sg-01234567); veriqta-monitoring (sg-07654321)
```

# Part 25: Collect IAM Instance Profiles

An EC2 instance can be associated with an IAM instance profile.

AWS exposes the profile information in the instance data.

Example structure:

```python
"IamInstanceProfile": {
    "Arn": "arn:aws:iam::123456789012:instance-profile/VeriqtaAppRole",
```

Retrieve safely:

```python
profile = instance.get(
    "IamInstanceProfile"

if profile:
    iam_profile_arn = profile.get(
        "Arn",
        "N/A"

else:
    iam_profile_arn = "N/A"
```

For a compact report, extract the final ARN component.

Create:

```python
def extract_profile_name(profile):
    if not profile:
        return "N/A"

    arn = profile.get("Arn")

    if not arn:
        return "N/A"

    return arn.rsplit("/", 1)[-1]
```


# Part 27: Calculate Instance Age

Launch time becomes much more useful when converted into age.

Import:

```python
from datetime import datetime, timezone
```

Then:

```python
def calculate_age_days(launch_time):
    if not launch_time:
        return None

    now = datetime.now(timezone.utc)

    return (
        now - launch_time
    ).days
```

Example:

```text
Launch Time: 2026-01-14
Age: 240 days
```

This helps identify:

* legacy infrastructure
* temporary servers that became permanent
* forgotten development instances
* long-running systems requiring modernization

Age alone does not mean a resource is bad.

It is an operational signal.

Now create the normalizer:

```python
def normalize_instance(
    instance,
    region,
    account_id,
    inventory_timestamp
):
    tags = tags_to_dict(
        instance.get("Tags", [])
    )

    launch_time = instance.get(
        "LaunchTime"
    )

    security_groups = instance.get(
        "SecurityGroups",
        []
    )

    return {
        "account_id": account_id,
        "region": region,
        "availability_zone": (
            instance.get(
                "Placement",
                {}
            ).get(
                "AvailabilityZone",
                "Unknown"
            )
        ),
        "instance_id": instance.get(
            "InstanceId",
            "Unknown"
        ),
        "instance_name": tags.get(
            "Name",
            "Unnamed"
        ),
        "instance_type": instance.get(
            "InstanceType",
            "Unknown"
        ),
        "state": (
            instance.get(
                "State",
                {}
            ).get(
                "Name",
                "unknown"
            )
        ),
        "private_ip": instance.get(
            "PrivateIpAddress",
            "N/A"
        ),
        "public_ip": instance.get(
            "PublicIpAddress",
            "N/A"
        ),
        "vpc_id": instance.get(
            "VpcId",
            "N/A"
        ),
        "subnet_id": instance.get(
            "SubnetId",
            "N/A"
        ),
        "security_groups": (
            format_security_groups(
                security_groups
            )
        ),
        "security_groups_text": (
            flatten_security_groups(
                security_groups
            )
        ),
        "ami_id": instance.get(
            "ImageId",
            "Unknown"
        ),
        "iam_instance_profile": (
            extract_profile_name(
                instance.get(
                    "IamInstanceProfile"
                )
            )
        ),
        "launch_time": (
            launch_time.isoformat()
            if launch_time
            else "Unknown"
        ),
        "age_days": (
            calculate_age_days(
                launch_time
            )
        ),
        "tags": tags,
        "inventory_timestamp": (
            inventory_timestamp
        )
    }
```

This function converts raw AWS data into a stable structure owned by our application.

That is important.

Instead of passing raw AWS API responses everywhere, we normalize them once.

# Part 31: Implement Pagination

Do not depend on a single:

```python
ec2.describe_instances()
```

call for a production inventory.

AWS recommends pagination for `DescribeInstances`, and Boto3 exposes a paginator specifically for this operation.

Use:

```python
paginator = ec2.get_paginator(
    "describe_instances"
)
```

Then:

```python
for page in paginator.paginate():
    for reservation in page.get(
        "Reservations",
```

```python
from botocore.exceptions import (

def collect_multi_region_inventory(
    session,

                "Error",
                {}
            )

                region,
                details.get(
                    "Code",
                    "Unknown"
                ),
                details.get(
                    "Message",
                    str(error)
                )
            )

            failed_regions.append(
                {
                    "region": region,
                    "error_code": details.get(
                        "Code",
                        "Unknown"
                    ),
                    "error_message": (
                        details.get(
                            "Message",
                            str(error)
                        )
                    )
                }
            )

        except BotoCoreError as error:
            logger.error(
                "BotoCore failure "
                "region=%s error=%s",
                region,
                error
            )

            failed_regions.append(
                {
                    "region": region,
                    "error_code": (
                        "BotoCoreError"
                    ),
                    "error_message": (
                        str(error)
                    )
                }
            )

    return inventory, failed_regions
```

If one region fails, we do not necessarily discard every successfully collected region.

We record partial failure.

# Part 36: Do Not Hide Partial Failures

Suppose:


That is misleading.

A better report says:

```text
Inventory Status: PARTIAL

eu-west-1
Reason: AccessDenied
```

Infrastructure automation must communicate confidence in its output.

```python
def main():
    args = parse_args()

    logger.info(
        "Starting VERIQTA "
        "EC2 inventory"
    )

    try:
        session = create_aws_session(
            profile_name=args.profile
        )

        account_id = (
            get_account_id(
                session
            )
        )

        logger.info(
            "Authenticated "
            "account=%s",
            account_id
        )

        if args.regions:
            regions = sorted(
                set(
                    args.regions
                )
            )
        else:
            regions = (
                discover_regions(
                    session
                )
            )

        logger.info(
            "Regions selected count=%d "
            "regions=%s",
            len(regions),
            ",".join(regions)
        )

        inventory_timestamp = (
            current_utc_timestamp()
        )

        inventory, failed_regions = (
            collect_multi_region_inventory(
                session=session,
                regions=regions,
                account_id=account_id,
                inventory_timestamp=(
                    inventory_timestamp
                ),
                logger=logger
            )
        )

        summary = build_summary(
            inventory=inventory,
            regions=regions,
            failed_regions=(
                failed_regions
            )
        )

        stopped_instances = (
            find_stopped_instances(
                inventory
            )
        )

        report_timestamp = (
            filename_timestamp()
        )

        json_report = {
            "metadata": {
                "account_id": (
                    account_id
                ),
                "inventory_timestamp": (
                    inventory_timestamp
                ),
                "regions": regions,
                "failed_regions": (
                    failed_regions
                )
            },
            "summary": summary,
            "instances": inventory
        }

        json_filename = (
            "ec2_inventory_"
            f"{report_timestamp}.json"
        )

        csv_filename = (
            "ec2_inventory_"
            f"{report_timestamp}.csv"
        )

        json_path = export_json(
            json_report,
            json_filename
        )

        csv_rows = (
            inventory_to_csv_rows(
                inventory
            )
        )

        csv_path = export_csv(
            csv_rows,
            csv_filename
        )

        logger.info(
            "JSON inventory created "
            "path=%s",
            json_path
        )

        if csv_path:
            logger.info(
                "CSV inventory created "
                "path=%s",
                csv_path
            )
        else:
            logger.info(
                "CSV report not created "
                "because no instances "
                "were returned."
            )

        print_summary(
            summary=summary,
            stopped_instances=(
                stopped_instances
            ),
            failed_regions=(
                failed_regions
            )
        )

        if failed_regions:
            logger.warning(
                "Inventory completed "
                "with partial failures."
            )

            return 2

        logger.info(
            "EC2 inventory completed "
            "successfully."
        )

        return 0

    except ProfileNotFound as error:
        logger.error(
            "AWS profile not found: %s",
            error
        )

        return 1

    except NoCredentialsError:
        logger.error(
            "AWS credentials "
            "could not be located."
        )

        return 1

    except ClientError as error:
        details = error.response.get(
            "Error",
            {}
        )

        logger.error(
            "AWS API request failed. "
            "Code=%s Message=%s",
            details.get(
                "Code",
                "Unknown"
            ),
            details.get(
                "Message",
                str(error)
            )
        )

        return 1

    except BotoCoreError as error:
        logger.error(
            "AWS SDK failure: %s",
            error
        )

        return 1

    except Exception:
        logger.exception(
            "Unexpected EC2 "
            "inventory failure."
        )

        return 1


if __name__ == "__main__":
    raise SystemExit(
        main()
    )
```
