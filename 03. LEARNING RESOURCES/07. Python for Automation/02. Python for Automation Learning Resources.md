Follow this order:

1. Install Python and understand the interpreter.
2. Learn variables and basic data types.
3. Learn strings.
4. Learn lists.
5. Learn dictionaries.
6. Learn sets and tuples.
7. Learn conditions.
8. Learn loops.
9. Learn functions.
10. Learn modules and imports.
11. Learn exceptions.
12. Learn files and directories.
13. Learn `pathlib`.
14. Learn environment variables.
15. Learn virtual environments.
16. Learn `pip`.
17. Learn JSON.
18. Learn YAML.
19. Learn CSV.
20. Learn regular expressions.
21. Learn logging.
22. Learn command-line arguments with `argparse`.
23. Learn `subprocess`.
24. Learn HTTP and REST APIs.
25. Learn Requests.
26. Learn authentication and API tokens.
27. Learn timeouts and retries.
28. Learn testing with pytest.
29. Build Linux automation scripts.
30. Build API automation scripts.
31. Learn Boto3 for AWS.
32. Learn cloud SDKs.
33. Learn Kubernetes API automation.
34. Integrate Python with CI/CD.

# Linux Command Automation

Learn:

```python
import subprocess
```

Example:

```python
import subprocess

result = subprocess.run(
    ["systemctl", "is-active", "nginx"],
    capture_output=True,
```

```python

```

# Logging

# Error Handling

Learn:

```python
try:
    operation()

```

Understand:

* Exceptions
* Specific exception types
* Cleanup
* Retries
* Timeouts
* Exit codes
* Partial failures

Do not use broad exception handling merely to hide failures.

# Production Python Automation Rules

Production automation should be:

* Version controlled
* Reviewed
* Tested
* Logged
* Documented
* Reproducible
* Observable
* Idempotent where appropriate
* Explicit about failures
* Careful with destructive operations

Always consider:

* Timeouts
* Retries
* Rate limits
* Authentication
* Permissions
* Partial failures
* Dependency versions
* API changes
* Rollback
* Cleanup

---

# Security

Never hardcode:

* Passwords
* API tokens
* AWS access keys
* Azure credentials
* Google Cloud credentials
* Database passwords
* SSH private keys
* Production secrets

Prefer:

* Environment variables where appropriate
* AWS IAM roles
* Workload identity
* OIDC
* AWS Secrets Manager
* Azure Key Vault
* Google Secret Manager
* HashiCorp Vault
* CI/CD secret stores

Apply least privilege.

# Dependency Management

Understand:

```text
pip
venv
requirements.txt
pyproject.toml
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate on Linux/macOS:

```bash
source .venv/bin/activate
```

Install packages:

```bash
python -m pip install requests
```

Do not depend on random globally installed packages for production automation.

# When to Use Bash vs Python

## Prefer Bash When

The task is primarily:

```text
Command
   |
Command
   |
Command
```

Examples:

* Run a few Linux commands
* Restart a service
* Simple deployment wrapper
* Small CI/CD step
* Basic file operation

## Consider Python When

The workflow involves:

* Complex logic
* APIs
* JSON
* YAML
* Large data structures
* Multiple services
* Cloud SDKs
* Detailed error handling
* Testing
* Retries
* Long-term maintenance
* Reusable automation

Bash and Python complement each other.

A DevOps engineer should understand both.
