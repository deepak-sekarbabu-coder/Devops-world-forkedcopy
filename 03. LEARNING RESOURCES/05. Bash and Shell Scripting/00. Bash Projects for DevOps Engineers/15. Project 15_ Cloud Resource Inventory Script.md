# Project 15: Cloud Resource Inventory Script

## AWS Infrastructure Discovery with Bash, AWS CLI, JSON, jq, CSV, and Structured Reporting

Cloud environments become difficult to operate when engineers cannot quickly answer:

```text
What infrastructure actually exists in this AWS account?
```

You may know that an application runs in AWS.

But during troubleshooting, migration, cost review, security review, or disaster recovery planning, you may need answers to questions such as:

```text
How many EC2 instances exist?

Which regions contain resources?

Which VPCs exist?

Which subnets belong to each VPC?

Which security groups exist?

How many S3 buckets are owned by this account?

Which load balancers are deployed?

Which RDS databases exist?

Which resources belong to production?

Which AWS account am I actually querying?
```

In this project, we will build:

```text
aws-inventory.sh
```

The script will create a read-only AWS infrastructure inventory.

Example:

```text
==========================================================================
                       AWS RESOURCE INVENTORY
==========================================================================

AWS Account:          123456789012
Identity:             arn:aws:sts::123456789012:assumed-role/InventoryRole/veriqta
Regions Scanned:      3

EC2 Instances:        12
VPCs:                 3
Subnets:              14
Security Groups:      22
S3 Buckets:           18
Load Balancers:       5
RDS Databases:        4

==========================================================================
```

The production version will export:

```text
Text report
JSON inventory
CSV files
```

The central lesson is:

```text
Cloud inventory should discover infrastructure without changing infrastructure.
```

This project is intentionally read-only.

# 4. Why Account Awareness Comes First

Before inventorying anything, answer:

```text
Which AWS account am I querying?
```

AWS provides:

```bash
aws sts get-caller-identity
```

This returns information about the IAM user or role whose credentials are currently being used, including the AWS account ID and ARN.

Run:

```bash
aws sts get-caller-identity
```

Example:

```json
{
  "UserId": "AROAXXXXXXXXX:veriqta",
  "Account": "123456789012",
  "Arn": "arn:aws:sts::123456789012:assumed-role/InventoryRole/veriqta"
}
```

---

# 5. Why This Matters

Imagine you believe you are querying:

```text
development
```

but your AWS profile actually points to:

```text
production
```

Even though this project is read-only, your report would be wrong.

For destructive scripts, this mistake would be much worse.

Every serious cloud automation script should make account identity visible.

# 23. Read EC2 Name Tag

The human-friendly instance name normally comes from:

```text
Tags
```

with:

```text
Key=Name
```

With `jq`:

```jq
([.Tags[]? | select(.Key == "Name") | .Value][0] // "")
```

The:

```text
?
```

prevents failure if Tags are missing.

---

# 24. Example EC2 Normalization

```bash
aws ec2 describe-instances \
    --region us-east-1 \
    --output json |
jq -c \
    --arg region "us-east-1" '
      .Reservations[].Instances[] |
      {
        region: $region,
        instance_id: .InstanceId,
        name: ([.Tags[]? |
          select(.Key == "Name") |
          .Value][0] // ""),
        state: .State.Name,
        instance_type: .InstanceType,
        private_ip: (.PrivateIpAddress // ""),
        public_ip: (.PublicIpAddress // ""),
        vpc_id: (.VpcId // ""),
        subnet_id: (.SubnetId // ""),
        availability_zone: (.Placement.AvailabilityZone // ""),
        launch_time: .LaunchTime
      }
    '
```

# 25. Terminated EC2 Instances

Be aware that AWS notes recently terminated EC2 instances can continue appearing in `describe-instances` results for a short period.

That means your inventory may temporarily include:

```text
terminated
```

Do not assume every returned EC2 object represents active infrastructure.

# 33. S3 Is Different

Run:



# 47. AWS Permissions

Your identity needs permission to describe/list the resources being inventoried.

Examples include read actions for:

```text
EC2
Elastic Load Balancing
RDS
S3
```

The exact IAM policy should follow least privilege.

Do not grant:

```text
AdministratorAccess
```

just because one inventory command receives AccessDenied.

---

# 48. What AccessDenied Means

Suppose:

```text
EC2 inventory works
RDS inventory returns AccessDenied
```

That does not mean:

```text
There are no RDS databases.
```

It means:

```text
The inventory is incomplete because RDS could not be queried.
```

A good inventory script must distinguish:

```text
zero resources
```

from:

```text
permission denied
```

---

# 49. Inventory Completeness Matters

This:

```text
RDS Databases: 0
```

is very different from:

```text
RDS Databases: UNKNOWN
Reason: AccessDenied
```

Never silently convert API failures into zero counts.

---

# 50. Pagination

AWS resource-list APIs can be paginated.

Commands such as:

```text
describe-instances
describe-vpcs
describe-load-balancers
describe-db-instances
```

support pagination. AWS CLI ordinarily handles paginated calls for you unless pagination is disabled.

For a complete inventory:

```text
Do not casually add --no-paginate.
```

---

# 51. Why Pagination Matters

Imagine:

```text
20 resources
```

in a lab.

Missing one page may not be obvious.

Imagine:

```text
4,000 resources
```

in an enterprise account.

Incomplete pagination creates a false inventory.

Inventory accuracy matters more as environments grow.

# 53. Beginner Version

We begin with one configured region.

Create:

```bash
nano aws-inventory.sh
```

Add:

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

if ! command -v aws >/dev/null 2>&1; then
    printf 'ERROR: AWS CLI is required.\n' >&2
    exit 3
fi

if ! command -v jq >/dev/null 2>&1; then
    printf 'ERROR: jq is required.\n' >&2
    exit 3
fi

if ! aws sts get-caller-identity >/dev/null 2>&1; then
    printf 'ERROR: AWS authentication failed.\n' >&2
    exit 3
fi

REGION=$(
    aws configure get region
)

if [[ -z "$REGION" ]]; then
    printf 'ERROR: No AWS region configured.\n' >&2
    exit 3
fi

ACCOUNT_ID=$(
    aws sts get-caller-identity \
        --query 'Account' \
        --output text
)

EC2_COUNT=$(
    aws ec2 describe-instances \
        --region "$REGION" \
        --output json |
    jq '[.Reservations[].Instances[]] | length'
)

VPC_COUNT=$(
    aws ec2 describe-vpcs \
        --region "$REGION" \
        --output json |
    jq '.Vpcs | length'
)

SUBNET_COUNT=$(
    aws ec2 describe-subnets \
        --region "$REGION" \
        --output json |
    jq '.Subnets | length'
)

SG_COUNT=$(
    aws ec2 describe-security-groups \
        --region "$REGION" \
        --output json |
    jq '.SecurityGroups | length'
)

S3_COUNT=$(
    aws s3api list-buckets \
        --output json |
    jq '.Buckets | length'
)

LB_COUNT=$(
    aws elbv2 describe-load-balancers \
        --region "$REGION" \
        --output json |
    jq '.LoadBalancers | length'
)

RDS_COUNT=$(
    aws rds describe-db-instances \
        --region "$REGION" \
        --output json |
    jq '.DBInstances | length'
)

printf '%s\n' \
    "=========================================================================="

printf '%s\n' \
    "                       AWS RESOURCE INVENTORY"

printf '%s\n' \
    "=========================================================================="

printf '\n%-24s %s\n' \
    "AWS Account:" "$ACCOUNT_ID"

printf '%-24s %s\n' \
    "Region:" "$REGION"

printf '\n%-24s %s\n' \
    "EC2 Instances:" "$EC2_COUNT"

printf '%-24s %s\n' \
    "VPCs:" "$VPC_COUNT"

printf '%-24s %s\n' \
    "Subnets:" "$SUBNET_COUNT"

printf '%-24s %s\n' \
    "Security Groups:" "$SG_COUNT"

printf '%-24s %s\n' \
    "S3 Buckets:" "$S3_COUNT"

printf '%-24s %s\n' \
    "Load Balancers:" "$LB_COUNT"

printf '%-24s %s\n' \
    "RDS Databases:" "$RDS_COUNT"

printf '%s\n' \
    "=========================================================================="
```

# 55. The Beginner Script Has an Important Weakness

Look carefully at:

```bash

    aws ec2 describe-instances ... |
    jq ...
)
```

If AWS returns an error, the pipeline can fail.

But if scripts are not designed carefully, failures can become misleading values or incomplete reports.

The production version will explicitly capture AWS errors.

# 58. Why Separate CSV Files

Trying to force:

```text
EC2
VPC
Subnet
RDS
S3
```

into one CSV creates awkward columns.

For example:

```text
instance_type
```

has no meaning for:

```text
S3 bucket
```

So we use:

```text
one JSON inventory
```

plus:

```text
one CSV per resource type
```

That produces cleaner data.

```bash
# ------------------------------------------------------------------
#
# Read-only cloud inventory utility.
#
# Inventory:
#   - EC2 Instances
#   - VPCs
#   - Subnets
#   - Security Groups
#   - S3 Buckets
#   - ELBv2 Load Balancers
#   - RDS DB Instances
#
# Exit codes:
#   0 = Complete inventory
#   1 = Inventory completed with one or more collection warnings
#   2 = Major collection failure
#   3 = Input/authentication/configuration error
#
# ------------------------------------------------------------------

AWS_PROFILE=""

show_help() {

    cat <<EOF
Usage:
  $0 [options]

Region options:

  --region REGION
      Inventory one AWS region.

  --all-regions
      Inventory all regions returned by EC2 DescribeRegions.

  If neither is supplied, the currently configured AWS region is used.

Authentication:

  --profile PROFILE
      Use a named AWS CLI profile.

Output:

  --output-dir DIR
      Base directory for reports.
      Default: ./reports

  --text
      Generate text summary only.

  --json
      Generate JSON inventory only.

  --csv
      Generate CSV exports only.

  --all-formats
      Generate text, JSON, and CSV.
      This is the default.

Other:

  --help
      Display this help.

Examples:

  $0

  $0 \
    --region us-east-1

  $0 \
    --profile production \
    --region us-east-1

  $0 \
    --profile production \
    --all-regions \
    --all-formats

  $0 \
    --all-regions \
    --output-dir ./inventory-reports
EOF
}


cleanup() {

    if [[ -n "${TMP_DIR:-}" &&
          -d "$TMP_DIR" ]]; then

        rm -rf -- "$TMP_DIR"
    fi
}


trap cleanup EXIT INT TERM


parse_arguments() {

    local explicit_format=false

    while [[ $# -gt 0 ]]; do

        case "$1" in

            --profile)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --profile requires a value.\n' >&2
                    exit 3
                }

                AWS_PROFILE="$2"
                shift 2
                ;;

            --region)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --region requires a value.\n' >&2
                    exit 3
                }

                REQUESTED_REGION="$2"
                shift 2
                ;;

            --all-regions)

                ALL_REGIONS=true
                shift
                ;;

            --output-dir)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --output-dir requires a value.\n' >&2
                    exit 3
                }

                OUTPUT_BASE="$2"
                shift 2
                ;;

            --text)

                if [[ "$explicit_format" == false ]]; then
                    EXPORT_TEXT=false
                    EXPORT_JSON=false
                    EXPORT_CSV=false
                    explicit_format=true
                fi

                EXPORT_TEXT=true
                shift
                ;;

            --json)

                if [[ "$explicit_format" == false ]]; then
                    EXPORT_TEXT=false
                    EXPORT_JSON=false
                    EXPORT_CSV=false
                    explicit_format=true
                fi

                EXPORT_JSON=true
                shift
                ;;

            --csv)

                if [[ "$explicit_format" == false ]]; then
                    EXPORT_TEXT=false
                    EXPORT_JSON=false
                    EXPORT_CSV=false
                    explicit_format=true
                fi

                EXPORT_CSV=true
                shift
                ;;

            --all-formats)

                EXPORT_TEXT=true
                EXPORT_JSON=true
                EXPORT_CSV=true
                explicit_format=true
                shift
                ;;

            --help|-h)

                show_help
                exit 0
                ;;

            *)

                printf 'ERROR: Unknown option: %s\n' \
                    "$1" >&2

                exit 3
                ;;
        esac
    done


    if [[ "$ALL_REGIONS" == true &&
          -n "$REQUESTED_REGION" ]]; then

        printf '%s\n' \
            'ERROR: Use --region or --all-regions, not both.' \
            >&2

        exit 3
    fi
}


check_dependencies() {

    local commands=(
        aws
        jq
        date
        mkdir
        mktemp
        rm
        wc
        cat
    )

    local cmd

    for cmd in "${commands[@]}"; do

        if ! command -v "$cmd" >/dev/null 2>&1; then

            printf 'ERROR: Required command missing: %s\n' \
                "$cmd" >&2

            exit 3
        fi
    done
}

validate_identity() {

    local identity_json

    if ! identity_json=$(
        aws_cli sts get-caller-identity \
            --output json 2>&1
    ); then

        printf '%s\n' \
            'ERROR: AWS authentication or STS identity lookup failed.' \
            >&2

        printf '%s\n' \
            "$identity_json" >&2

        exit 3
    fi


    ACCOUNT_ID=$(
        jq -r '.Account' \
            <<< "$identity_json"
    )


    CALLER_ARN=$(
        jq -r '.Arn' \
            <<< "$identity_json"
    )


    if [[ -z "$ACCOUNT_ID" ||
          "$ACCOUNT_ID" == "null" ]]; then

        printf 'ERROR: Unable to determine AWS account ID.\n' >&2
        exit 3
    fi
}


determine_regions() {

    local configured_region
    local regions_text


    if [[ -n "$REQUESTED_REGION" ]]; then

        REGIONS=(
            "$REQUESTED_REGION"
        )

        return
    fi


    if [[ "$ALL_REGIONS" == true ]]; then

        if ! regions_text=$(
            aws_cli ec2 describe-regions \
                --query 'Regions[].RegionName' \
                --output text \
                2>&1
        ); then

            printf '%s\n' \
                'ERROR: Unable to discover AWS regions.' \
                >&2

            printf '%s\n' \
                "$regions_text" >&2

            exit 3
        fi


        read -r -a REGIONS \
            <<< "$regions_text"


        if (( ${#REGIONS[@]} == 0 )); then

            printf 'ERROR: No AWS regions returned.\n' >&2
            exit 3
        fi

        return
    fi


    configured_region=$(
        aws_cli configure get region 2>/dev/null || true
    )


    if [[ -z "$configured_region" ]]; then

        configured_region="${AWS_REGION:-${AWS_DEFAULT_REGION:-}}"
    fi


    if [[ -z "$configured_region" ]]; then

        printf '%s\n' \
            'ERROR: No AWS region configured.' \
            >&2

        printf '%s\n' \
            'Use --region REGION or --all-regions.' \
            >&2

        exit 3
    fi


    REGIONS=(
        "$configured_region"
    )
}


initialize_report() {

    RUN_TIMESTAMP=$(
        date '+%Y-%m-%d-%H%M%S'
    )


    mkdir -p "$OUTPUT_BASE"


    REPORT_DIR="$OUTPUT_BASE/aws-inventory-$RUN_TIMESTAMP"

    mkdir -p "$REPORT_DIR"


    TMP_DIR=$(
        mktemp -d
    )


    : > "$TMP_DIR/ec2.jsonl"
    : > "$TMP_DIR/vpcs.jsonl"
    : > "$TMP_DIR/subnets.jsonl"
    : > "$TMP_DIR/security-groups.jsonl"
    : > "$TMP_DIR/load-balancers.jsonl"
    : > "$TMP_DIR/rds.jsonl"
    : > "$TMP_DIR/s3.jsonl"
    : > "$TMP_DIR/errors.log"
}


record_warning() {

    local service="$1"
    local region="$2"
    local message="$3"

    ((COLLECTION_WARNINGS+=1))

    printf '[%s] service=%s region=%s error=%s\n' \
        "$(date '+%Y-%m-%d %H:%M:%S')" \
        "$service" \
        "$region" \
        "$message" \
        >> "$TMP_DIR/errors.log"
}


collect_ec2() {

    local region="$1"
    local result

    if ! result=$(
        aws_cli ec2 describe-instances \
            --region "$region" \
            --output json \
            2>&1
    ); then

        record_warning \
            "ec2" \
            "$region" \
            "$result"

        return
    fi


    jq -c \
        --arg region "$region" '
          .Reservations[].Instances[] |
          {
            region: $region,
            instance_id: .InstanceId,
            name: (
              [.Tags[]? |
                select(.Key == "Name") |
                .Value][0] // ""
            ),
            state: .State.Name,
            instance_type: .InstanceType,
            private_ip: (.PrivateIpAddress // ""),
            public_ip: (.PublicIpAddress // ""),
            vpc_id: (.VpcId // ""),
            subnet_id: (.SubnetId // ""),
            availability_zone: (
              .Placement.AvailabilityZone // ""
            ),
            launch_time: (.LaunchTime // "")
          }
        ' \
        <<< "$result" \
        >> "$TMP_DIR/ec2.jsonl"
}

collect_regional_resources() {

    local region

    for region in "${REGIONS[@]}"; do

        printf 'Collecting region: %s\n' \
            "$region"

        collect_ec2 "$region"

        collect_vpcs "$region"

        collect_subnets "$region"

        collect_security_groups "$region"

        collect_load_balancers "$region"

        collect_rds "$region"
    done
}


count_json_lines() {

    local file="$1"

    awk 'NF {count++} END {print count+0}' \
        "$file"
}


build_json_array() {

    local input_file="$1"
    local output_file="$2"

    if [[ -s "$input_file" ]]; then

        jq -s '.' \
            "$input_file" \
            > "$output_file"

    else

        printf '[]\n' \
            > "$output_file"
    fi
}

create_json_inventory() {

    [[ "$EXPORT_JSON" == true ]] || return


    local regions_json

    regions_json=$(
        printf '%s\n' "${REGIONS[@]}" |
        jq -R . |
        jq -s .
    )


    jq -n \
        --arg generated_at "$RUN_TIMESTAMP" \
        --arg account_id "$ACCOUNT_ID" \
        --arg caller_arn "$CALLER_ARN" \
        --argjson regions "$regions_json" \
        --argfile ec2 "$TMP_DIR/ec2.json" \
        --argfile vpcs "$TMP_DIR/vpcs.json" \
        --argfile subnets "$TMP_DIR/subnets.json" \
        --argfile security_groups "$TMP_DIR/security-groups.json" \
        --argfile s3 "$TMP_DIR/s3.json" \
        --argfile load_balancers "$TMP_DIR/load-balancers.json" \
        --argfile rds "$TMP_DIR/rds.json" \
        '{
          metadata: {
            generated_at: $generated_at,
            aws_account: $account_id,
            caller_arn: $caller_arn,
            regions: $regions
          },
          summary: {
            ec2_instances: ($ec2 | length),
            vpcs: ($vpcs | length),
            subnets: ($subnets | length),
            security_groups: ($security_groups | length),
            s3_buckets: ($s3 | length),
            load_balancers: ($load_balancers | length),
            rds_databases: ($rds | length)
          },
          resources: {
            ec2_instances: $ec2,
            vpcs: $vpcs,
            subnets: $subnets,
            security_groups: $security_groups,
            s3_buckets: $s3,
            load_balancers: $load_balancers,
            rds_databases: $rds
          }
        }' \
        > "$REPORT_DIR/inventory.json"
}

    local ec2_count
    local vpc_count
    local subnet_count
    local sg_count
    local s3_count
    local lb_count
    local rds_count

    ec2_count=$(
        count_json_lines \
            "$TMP_DIR/ec2.jsonl"
    )

    vpc_count=$(
        count_json_lines \
            "$TMP_DIR/vpcs.jsonl"
    )

    subnet_count=$(
        count_json_lines \
            "$TMP_DIR/subnets.jsonl"
    )

    sg_count=$(
        count_json_lines \
            "$TMP_DIR/security-groups.jsonl"
    )

    s3_count=$(
        count_json_lines \
            "$TMP_DIR/s3.jsonl"
    )

    lb_count=$(
        count_json_lines \
            "$TMP_DIR/load-balancers.jsonl"
    )

    rds_count=$(
        count_json_lines \
            "$TMP_DIR/rds.jsonl"
    )


    {
        printf '%s\n' \
            "=========================================================================="

        printf '%s\n' \
            "                       AWS RESOURCE INVENTORY"

        printf '%s\n' \
            "=========================================================================="

        printf '\n%-24s %s\n' \

        printf '%-24s %s\n' \
            "AWS Account:" "$ACCOUNT_ID"

        printf '%-24s %s\n' \
            "Identity:" "$CALLER_ARN"

        printf '%-24s %s\n' \
            "Regions Scanned:" "${#REGIONS[@]}"


        printf '\n%s\n' \
            "------------------------------- SUMMARY ----------------------------------"


        printf '%-24s %s\n' \
            "EC2 Instances:" "$ec2_count"

        printf '%-24s %s\n' \
            "VPCs:" "$vpc_count"

        printf '%-24s %s\n' \
            "Subnets:" "$subnet_count"

        printf '%-24s %s\n' \
            "Security Groups:" "$sg_count"

        printf '%-24s %s\n' \
            "S3 Buckets:" "$s3_count"

        printf '%-24s %s\n' \
            "Load Balancers:" "$lb_count"

        printf '%-24s %s\n' \
            "RDS Databases:" "$rds_count"


        printf '\n%s\n' \
            "---------------------------- REGIONS SCANNED -----------------------------"

        printf '%s\n' \
            "${REGIONS[@]}"


        if (( COLLECTION_WARNINGS > 0 )); then

            printf '\n%s\n' \

}
```

* Store
* Visualize
* Diff
