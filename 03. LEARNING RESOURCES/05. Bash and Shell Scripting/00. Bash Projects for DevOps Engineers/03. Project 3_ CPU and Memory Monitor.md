# Project 3: CPU and Memory Monitor

CPU and memory problems are two of the first things engineers investigate when a Linux server becomes slow.

But there is a common mistake.

A server showing high CPU is not automatically unhealthy.

A server showing low free memory is not automatically running out of memory.

Linux deliberately uses available memory for cache, processes can temporarily spike CPU, and load average tells a different story from CPU utilization.

In this project, we will build a resource monitoring script that does more than print a few percentages.

We will build:

```text
resource-monitor.sh
```

The script will monitor:

* CPU utilization
* Load average
* Total memory
* Available memory
* Memory usage
* Swap usage
* Top CPU-consuming processes
* Top memory-consuming processes

It will also classify the server as:

```text
OK
WARNING
CRITICAL
```

and detect conditions such as:

```text
CPU HIGH
MEMORY HIGH
SWAP HIGH
```

A completed run might look like:

# 8. CPU Utilization vs Load Average

These two metrics are often confused.

They are not the same.

## CPU utilization

CPU utilization tells us approximately how much processor time is busy.

Example:

```text
CPU utilization: 87%
```

## Load average

Load average represents the average number of tasks that are runnable or waiting in certain uninterruptible states.

Example:

```text
Load average: 3.10 2.84 2.55
```

These values correspond approximately to:

```text
1 minute
5 minutes
15 minutes
```

Run:

```bash
uptime
```

Example:

```text
11:22:17 up 9 days, 4:13, 2 users, load average: 3.10, 2.84, 2.55
```

You can also read:

```bash
cat /proc/loadavg
```

Example:

```text
3.10 2.84 2.55 4/316 24891
```

The first three numbers are the same load averages.

---

# 9. Why CPU Count Matters

Suppose a server has:

```text
1 logical CPU
```

and load average is:

```text
4.0
```

That means the workload is heavily queued.

Now imagine a server with:

```text
32 logical CPUs
```

and load average:

```text
4.0
```

That is usually not concerning.

So load average must be interpreted relative to CPU capacity.

Check:

```bash
nproc
```

Then:

```bash
cat /proc/loadavg
```

Do not interpret load average without knowing the available CPUs.

# 10. Read CPU Statistics From `/proc/stat`

Run:

```bash
head -n 1 /proc/stat
```

Example:

```text
cpu  125230 450 38120 8921734 8210 0 4790 0 0 0
```

The fields represent accumulated CPU time in several categories.

Common fields include:

```text
user
nice
system
idle
iowait
irq
softirq
steal
guest
guest_nice
```

The values are cumulative since boot.

That means one reading alone does not directly tell us CPU utilization.

We need two readings.

---

# 11. How CPU Utilization Is Calculated

Conceptually:

```text
Read CPU counters
      |
      v
Wait briefly
      |
      v
Read CPU counters again
      |
      v
Calculate difference
      |
      v
Compare idle time with total time
```

We can approximate:

```text
CPU utilization =
100 × (total_delta - idle_delta) / total_delta
```

This is more meaningful than trying to extract a single percentage from `/proc/stat`.

---

# 12. Build a CPU Sampling Function

We will read `/proc/stat` twice.

Start with:

```bash
read_cpu_times() {
    read -r cpu user nice system idle iowait irq softirq steal guest guest_nice \
        < /proc/stat

    CPU_IDLE=$((idle + iowait))

    CPU_TOTAL=$(
        (
            user +
            nice +
            system +
            idle +
            iowait +
            irq +
            softirq +
            steal
        )
    )
}
```

But we need two separate samples, so we will implement this more carefully.

# 13. A Better CPU Calculation

Use:

```bash
get_cpu_usage() {

    local cpu
    local user
    local nice
    local system
    local idle
    local iowait
    local irq
    local softirq
    local steal
    local guest
    local guest_nice

    read -r cpu user nice system idle iowait irq softirq steal guest guest_nice \
        < /proc/stat

    local idle1=$((idle + iowait))
    local total1=$((user + nice + system + idle + iowait + irq + softirq + steal))

    sleep 1

    read -r cpu user nice system idle iowait irq softirq steal guest guest_nice \
        < /proc/stat

    local idle2=$((idle + iowait))
    local total2=$((user + nice + system + idle + iowait + irq + softirq + steal))

    local idle_delta=$((idle2 - idle1))
    local total_delta=$((total2 - total1))

    if (( total_delta == 0 )); then
        CPU_USAGE=0
    else
        CPU_USAGE=$(
            awk -v idle="$idle_delta" -v total="$total_delta" \
                'BEGIN {
                    printf "%.0f", 100 * (total-idle) / total
                }'
        )
    fi
}
```

This gives us an approximate CPU utilization across the sampling interval.

# 14. Why We Sample Instead of Using `top`

You could extract CPU data from:

```bash
top -bn1
```

But parsing `top` can vary across systems and versions.

Reading `/proc/stat` gives us a more direct Linux kernel source.

That is why `/proc` is useful.

# 15. Understanding `/proc`

`/proc` is a virtual filesystem.

It exposes kernel and process information.

Examples:

```text
/proc/stat
/proc/loadavg
/proc/meminfo
/proc/cpuinfo
/proc/uptime
/proc/<PID>/
```

It does not behave like a normal directory full of files stored on disk.

The kernel generates much of the content dynamically.

We can get:

```bash
MEM_TOTAL_KB=$(awk '/^MemTotal:/ {print $2}' /proc/meminfo)
```

And:

```bash
MEM_AVAILABLE_KB=$(awk '/^MemAvailable:/ {print $2}' /proc/meminfo)
```

Calculate used memory:

```bash
MEM_USED_KB=$((MEM_TOTAL_KB - MEM_AVAILABLE_KB))
```

Calculate percentage:

```bash
MEMORY_USAGE=$(
    awk -v used="$MEM_USED_KB" -v total="$MEM_TOTAL_KB" \
        'BEGIN {
            if (total > 0)
                printf "%.0f", (used/total)*100
            else
                print 0
        }'
)
```

# 20. Why We Use MemAvailable

Suppose:

```text
Total memory:     8 GB
Free memory:      500 MB
Available memory: 3 GB
```

Looking only at free memory might make the server appear nearly out of RAM.

But Linux can reclaim some caches when applications need memory.

That is why:

```text
MemAvailable
```

is often more useful than:

```text
MemFree
```

for a first-level health check.

# 23. Swap Usage Does Not Automatically Mean Failure

A Linux machine using swap is not automatically unhealthy.

Some memory pages may remain in swap even after pressure has decreased.

You need to distinguish:

```text
Some swap is used
```

from:

```text
The server is actively swapping heavily
```

That is why we also use:

```bash
vmstat
```

# 29. Process CPU Is Not the Same as System CPU

If:

```text
java = 120% CPU
```

you may wonder how a process exceeds 100 percent.

On multi-core Linux systems, tools can report process CPU relative to a single logical CPU.

A multithreaded process may consume more than one full CPU.

For example:

```text
200%
```

can mean roughly two logical CPUs worth of processor time.

Interpret process CPU in the context of:

```bash
nproc
```

```bash
update_overall_status() {

    local status="$1"

    if [[ "$status" == "CRITICAL" ]]; then
        OVERALL_STATUS="CRITICAL"

    elif [[ "$status" == "WARNING" &&
            "$OVERALL_STATUS" == "OK" ]]; then

}
```

# 40. Build Swap Collection Function

Use:

```bash
collect_swap() {

    SWAP_TOTAL_KB=$(awk '/^SwapTotal:/ {print $2}' /proc/meminfo)

    SWAP_FREE_KB=$(awk '/^SwapFree:/ {print $2}' /proc/meminfo)

    SWAP_USED_KB=$((SWAP_TOTAL_KB - SWAP_FREE_KB))

    if (( SWAP_TOTAL_KB == 0 )); then

        SWAP_USAGE=0
        TOTAL_SWAP_GIB="0.0"
        USED_SWAP_MIB="0"

    else

        SWAP_USAGE=$(
            awk \
                -v used="$SWAP_USED_KB" \
                -v total="$SWAP_TOTAL_KB" \
                'BEGIN {
                    printf "%.0f", (used/total)*100
                }'
        )

        TOTAL_SWAP_GIB=$(
            awk -v kb="$SWAP_TOTAL_KB" \
                'BEGIN {
                    printf "%.1f", kb/1024/1024
                }'
        )

        USED_SWAP_MIB=$(
            awk -v kb="$SWAP_USED_KB" \
                'BEGIN {
                    printf "%.0f", kb/1024
                }'
        )
```

# 41. Complete Working Script

Replace the contents of `resource-monitor.sh` with:

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

# ------------------------------------------------------------------
# CPU and Memory Resource Monitor
# ------------------------------------------------------------------
#
# Exit codes:
#   0 = OK
#   1 = WARNING
#   2 = CRITICAL
#   3 = Script/configuration error
#
# ------------------------------------------------------------------

CPU_WARNING=80
CPU_CRITICAL=90

MEMORY_WARNING=85
MEMORY_CRITICAL=95

SWAP_WARNING=30
SWAP_CRITICAL=60

TOP_COUNT=5
ENABLE_LOG=true

OVERALL_STATUS="OK"

CPU_USAGE=0
CPU_STATUS="UNKNOWN"

LOAD_1="0"
LOAD_5="0"
LOAD_15="0"
LOAD_PER_CPU="0"

CPU_COUNT=0

MEM_TOTAL_KB=0
MEM_AVAILABLE_KB=0
MEM_USED_KB=0
MEMORY_USAGE=0
MEMORY_STATUS="UNKNOWN"

TOTAL_MEMORY_GIB="0"
AVAILABLE_MEMORY_GIB="0"

SWAP_TOTAL_KB=0
SWAP_FREE_KB=0
SWAP_USED_KB=0
SWAP_USAGE=0
SWAP_STATUS="UNKNOWN"

TOTAL_SWAP_GIB="0"
USED_SWAP_MIB="0"

TIMESTAMP=""
HOSTNAME_VALUE=""

SCRIPT_DIR=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)
readonly SCRIPT_DIR

LOG_DIR="$SCRIPT_DIR/logs"
LOG_FILE="$LOG_DIR/resource-monitor.log"


show_help() {

    cat <<EOF
Usage:
  $0 [options]

Options:
  --cpu N         CPU warning threshold percentage
  --memory N      Memory warning threshold percentage
  --swap N        Swap warning threshold percentage
  --top N         Number of top processes to display
  --no-log        Disable logging
  --help          Display this help

Examples:
  $0
  $0 --cpu 80 --memory 85
  $0 --cpu 70 --memory 80 --swap 20
  $0 --top 10
EOF
}


is_integer() {
    [[ "$1" =~ ^[0-9]+$ ]]
}


validate_percentage() {

    local name="$1"
    local value="$2"

    if ! is_integer "$value"; then

        printf 'ERROR: %s must be an integer.\n' "$name" >&2
        exit 3
    fi

    if (( value < 1 || value > 100 )); then

        printf 'ERROR: %s must be between 1 and 100.\n' "$name" >&2
        exit 3
    fi
}


parse_arguments() {

    while [[ $# -gt 0 ]]; do

        case "$1" in

            --cpu)

                if [[ $# -lt 2 ]]; then
                    printf 'ERROR: --cpu requires a value.\n' >&2
                    exit 3
                fi

                validate_percentage "CPU threshold" "$2"

                CPU_WARNING="$2"
                CPU_CRITICAL=$((CPU_WARNING + 10))

                if (( CPU_CRITICAL > 100 )); then
                    CPU_CRITICAL=100
                fi

                shift 2
                ;;

            --memory)

                if [[ $# -lt 2 ]]; then
                    printf 'ERROR: --memory requires a value.\n' >&2
                    exit 3
                fi

                validate_percentage "Memory threshold" "$2"

                MEMORY_WARNING="$2"
                MEMORY_CRITICAL=$((MEMORY_WARNING + 10))

                if (( MEMORY_CRITICAL > 100 )); then
                    MEMORY_CRITICAL=100
                fi

                shift 2
                ;;

            --swap)

                if [[ $# -lt 2 ]]; then
                    printf 'ERROR: --swap requires a value.\n' >&2
                    exit 3
                fi

                validate_percentage "Swap threshold" "$2"

                SWAP_WARNING="$2"
                SWAP_CRITICAL=$((SWAP_WARNING + 30))

                if (( SWAP_CRITICAL > 100 )); then
                    SWAP_CRITICAL=100
                fi

                shift 2
                ;;

            --top)

                if [[ $# -lt 2 ]]; then
                    printf 'ERROR: --top requires a value.\n' >&2
                    exit 3
                fi

                if ! is_integer "$2" || (( $2 < 1 || $2 > 50 )); then

                    printf 'ERROR: --top must be between 1 and 50.\n' >&2
                    exit 3
                fi

                TOP_COUNT="$2"
                shift 2
                ;;

            --no-log)

                ENABLE_LOG=false
                shift
                ;;

            --help|-h)

                show_help
                exit 0
                ;;

            *)

                printf 'ERROR: Unknown option: %s\n' "$1" >&2
                show_help
                exit 3
                ;;
        esac

    done
}


check_dependencies() {

    local commands=(
        awk
        date
        free
        hostname
        nproc
        ps
        sleep
        vmstat
    )

    local cmd
    local missing=0

    for cmd in "${commands[@]}"; do

        if ! command -v "$cmd" >/dev/null 2>&1; then

            printf 'ERROR: Required command missing: %s\n' "$cmd" >&2
            missing=1

        fi

    done

    if (( missing != 0 )); then
        exit 3
    fi
}


get_status() {

    local value="$1"
    local warning="$2"
    local critical="$3"

    if (( value >= critical )); then
        printf 'CRITICAL'

    elif (( value >= warning )); then
        printf 'WARNING'

    else
        printf 'OK'
    fi
}


update_overall_status() {

    local status="$1"

    if [[ "$status" == "CRITICAL" ]]; then

        OVERALL_STATUS="CRITICAL"

    elif [[ "$status" == "WARNING" &&
            "$OVERALL_STATUS" == "OK" ]]; then

        OVERALL_STATUS="WARNING"
    fi
}


get_cpu_usage() {

    local cpu
    local user
    local nice
    local system
    local idle
    local iowait
    local irq
    local softirq
    local steal
    local guest
    local guest_nice

    read -r cpu user nice system idle iowait irq softirq steal guest guest_nice \
        < /proc/stat

    local idle1=$((idle + iowait))

    local total1=$(
        (
            user +
            nice +
            system +
            idle +
            iowait +
            irq +
            softirq +
            steal
        )
    )

    sleep 1

    read -r cpu user nice system idle iowait irq softirq steal guest guest_nice \
        < /proc/stat

    local idle2=$((idle + iowait))

    local total2=$(
        (
            user +
            nice +
            system +
            idle +
            iowait +
            irq +
            softirq +
            steal
        )
    )

    local idle_delta=$((idle2 - idle1))
    local total_delta=$((total2 - total1))

    if (( total_delta == 0 )); then

        CPU_USAGE=0

    else

        CPU_USAGE=$(
            awk \
                -v idle="$idle_delta" \
                -v total="$total_delta" \
                'BEGIN {
                    printf "%.0f", 100 * (total-idle) / total
                }'
        )

    fi
}


collect_load() {

    CPU_COUNT=$(nproc)

    read -r LOAD_1 LOAD_5 LOAD_15 _ < /proc/loadavg

    LOAD_PER_CPU=$(
        awk \
            -v load="$LOAD_1" \
            -v cpus="$CPU_COUNT" \
            'BEGIN {
                if (cpus > 0)
                    printf "%.2f", load/cpus
                else
                    print "0.00"
            }'
    )
}


collect_memory() {

    MEM_TOTAL_KB=$(
        awk '/^MemTotal:/ {print $2}' /proc/meminfo
    )

    MEM_AVAILABLE_KB=$(
        awk '/^MemAvailable:/ {print $2}' /proc/meminfo
    )

    MEM_USED_KB=$((MEM_TOTAL_KB - MEM_AVAILABLE_KB))

    MEMORY_USAGE=$(
        awk \
            -v used="$MEM_USED_KB" \
            -v total="$MEM_TOTAL_KB" \
            'BEGIN {
                if (total > 0)
                    printf "%.0f", (used/total)*100
                else
                    print 0
            }'
    )

    TOTAL_MEMORY_GIB=$(
        awk -v kb="$MEM_TOTAL_KB" \
            'BEGIN {
                printf "%.1f", kb/1024/1024
            }'
    )

    AVAILABLE_MEMORY_GIB=$(
        awk -v kb="$MEM_AVAILABLE_KB" \
            'BEGIN {
                printf "%.1f", kb/1024/1024
            }'
    )
}


collect_swap() {

    SWAP_TOTAL_KB=$(
        awk '/^SwapTotal:/ {print $2}' /proc/meminfo
    )

    SWAP_FREE_KB=$(
        awk '/^SwapFree:/ {print $2}' /proc/meminfo
    )

    SWAP_USED_KB=$((SWAP_TOTAL_KB - SWAP_FREE_KB))

    if (( SWAP_TOTAL_KB == 0 )); then

        SWAP_USAGE=0
        TOTAL_SWAP_GIB="0.0"
        USED_SWAP_MIB="0"

    else

        SWAP_USAGE=$(
            awk \
                -v used="$SWAP_USED_KB" \
                -v total="$SWAP_TOTAL_KB" \
                'BEGIN {
                    printf "%.0f", (used/total)*100
                }'
        )

        TOTAL_SWAP_GIB=$(
            awk -v kb="$SWAP_TOTAL_KB" \
                'BEGIN {
                    printf "%.1f", kb/1024/1024
                }'
        )

        USED_SWAP_MIB=$(
            awk -v kb="$SWAP_USED_KB" \
                'BEGIN {
                    printf "%.0f", kb/1024
                }'
        )

    fi
}


evaluate_resources() {

    CPU_STATUS=$(
        get_status \
            "$CPU_USAGE" \
            "$CPU_WARNING" \
            "$CPU_CRITICAL"
    )

    MEMORY_STATUS=$(
        get_status \
            "$MEMORY_USAGE" \
            "$MEMORY_WARNING" \
            "$MEMORY_CRITICAL"
    )

    if (( SWAP_TOTAL_KB == 0 )); then

        SWAP_STATUS="OK"

    else

        SWAP_STATUS=$(
            get_status \
                "$SWAP_USAGE" \
                "$SWAP_WARNING" \
                "$SWAP_CRITICAL"
        )

    fi

    update_overall_status "$CPU_STATUS"
    update_overall_status "$MEMORY_STATUS"
    update_overall_status "$SWAP_STATUS"
}


print_top_cpu() {

    printf '\n%s\n' \
        "----------------------- TOP CPU PROCESSES -------------------------------"

    ps -eo pid,user,comm,%cpu,%mem \
        --sort=-%cpu |
        head -n $((TOP_COUNT + 1))
}


print_top_memory() {

    printf '\n%s\n' \
        "---------------------- TOP MEMORY PROCESSES ------------------------------"

    ps -eo pid,user,comm,%cpu,%mem \
        --sort=-%mem |
        head -n $((TOP_COUNT + 1))
}


write_log() {

    if [[ "$ENABLE_LOG" != true ]]; then
        return
    fi

    mkdir -p "$LOG_DIR"

    printf '[%s] host=%s cpu=%s%% memory=%s%% swap=%s%% load=%s status=%s\n' \
        "$TIMESTAMP" \
        "$HOSTNAME_VALUE" \
        "$CPU_USAGE" \
        "$MEMORY_USAGE" \
        "$SWAP_USAGE" \
        "$LOAD_1" \
        "$OVERALL_STATUS" \
        >> "$LOG_FILE"
}


print_report() {

    printf '%s\n' \
        "=========================================================================="

    printf '%s\n' \
        "                       RESOURCE MONITOR REPORT"

    printf '%s\n' \
        "=========================================================================="

    printf '%-23s %s\n' \
        "Timestamp:" "$TIMESTAMP"

    printf '%-23s %s\n' \
        "Hostname:" "$HOSTNAME_VALUE"

    printf '\n%-23s %s%%\n' \
        "CPU Warning:" "$CPU_WARNING"

    printf '%-23s %s%%\n' \
        "CPU Critical:" "$CPU_CRITICAL"

    printf '%-23s %s%%\n' \
        "Memory Warning:" "$MEMORY_WARNING"

    printf '%-23s %s%%\n' \
        "Memory Critical:" "$MEMORY_CRITICAL"

    printf '%-23s %s%%\n' \
        "Swap Warning:" "$SWAP_WARNING"

    printf '%-23s %s%%\n' \
        "Swap Critical:" "$SWAP_CRITICAL"

    printf '\n%s\n' \
        "------------------------------- CPU --------------------------------------"

    printf '%-23s %s%%\n' \
        "CPU Utilization:" "$CPU_USAGE"

    printf '%-23s %s %s %s\n' \
        "Load Average:" "$LOAD_1" "$LOAD_5" "$LOAD_15"

    printf '%-23s %s\n' \
        "Logical CPUs:" "$CPU_COUNT"

    printf '%-23s %s\n' \
        "Load Per CPU:" "$LOAD_PER_CPU"

    printf '%-23s %s\n' \
        "CPU Status:" "$CPU_STATUS"

    printf '\n%s\n' \
        "------------------------------ MEMORY ------------------------------------"

    printf '%-23s %s GiB\n' \
        "Total Memory:" "$TOTAL_MEMORY_GIB"

    printf '%-23s %s GiB\n' \
        "Available Memory:" "$AVAILABLE_MEMORY_GIB"

    printf '%-23s %s%%\n' \
        "Memory Usage:" "$MEMORY_USAGE"

    printf '%-23s %s\n' \
        "Memory Status:" "$MEMORY_STATUS"

    printf '\n%s\n' \
        "------------------------------- SWAP -------------------------------------"

    printf '%-23s %s GiB\n' \
        "Total Swap:" "$TOTAL_SWAP_GIB"

    printf '%-23s %s MiB\n' \
        "Used Swap:" "$USED_SWAP_MIB"

    printf '%-23s %s%%\n' \
        "Swap Usage:" "$SWAP_USAGE"

    printf '%-23s %s\n' \
        "Swap Status:" "$SWAP_STATUS"

    print_top_cpu
    print_top_memory

    printf '\n%s\n' \
        "--------------------------------------------------------------------------"

    printf '%-23s %s\n' \
        "Overall Status:" "$OVERALL_STATUS"

    printf '%s\n' \
        "=========================================================================="
}


return_status() {

    case "$OVERALL_STATUS" in

        OK)
            return 0
            ;;

        WARNING)
            return 1
            ;;

        CRITICAL)
            return 2
            ;;

        *)
            return 3
            ;;
    esac
}


main() {

    parse_arguments "$@"

    check_dependencies

    TIMESTAMP=$(date '+%Y-%m-%d %H:%M:%S')
    HOSTNAME_VALUE=$(hostname)

    get_cpu_usage
    collect_load
    collect_memory
    collect_swap

    evaluate_resources

    print_report

    write_log

    return_status
}


main "$@"
exit $?
```

# 63. RSS and VSZ

When inspecting processes, you may see:

```text
RSS
VSZ
```

They are not the same.

## RSS

Resident Set Size.

Approximately how much physical memory is currently resident for the process.

## VSZ

Virtual memory size.

It can include:

* Mapped memory
* Shared libraries
* Allocated address space
* Memory not physically resident

Do not assume a huge VSZ value means the process is actually consuming that much physical RAM.

```bash

```


```text

```

the server may not currently be swapping actively.

If you repeatedly see:

```text
si = hundreds or thousands

```

then memory pressure may be active.

# 67. Swap Thrashing

Severe memory pressure can result in constant movement between RAM and swap.

Symptoms can include:

* Very slow application response
* High disk activity
* Low effective throughput
* High load
* Large `si` and `so`
* Increased latency

This situation is sometimes referred to as thrashing.

More memory may be required, but you should still investigate the workload before simply resizing the machine.

---

# 68. CPU Steal Time

On virtualized systems, CPU problems may involve:

```text
steal
```

Run:

```bash
vmstat 1
```

The CPU columns may include:

```text
st
```

Steal time represents time when the virtual CPU wanted to run but the hypervisor was servicing another workload.

Persistent high steal time can indicate contention at the virtualization layer.

That is different from your application simply consuming CPU.

# 69. I/O Wait

Run:

```bash
vmstat 1
```

Look for:

```text
wa
```

High I/O wait may mean the CPU is waiting on storage.

Possible causes:

* Slow disks
* Saturated EBS volume
* Database I/O
* NFS latency
* Heavy logging
* Backup operations
* Filesystem problems

A slow server is not always a CPU problem.

# 90. Security Considerations

This script is read-only.

It does not:

* Kill processes
* Restart services
* Change limits
* Clear caches
* Disable swap

That is intentional.

Do not automatically add commands such as:

```bash
kill -9
```

or:

```bash
swapoff -a
```

or:

```bash
echo 3 > /proc/sys/vm/drop_caches
```

just because a threshold is crossed.

These actions can create bigger problems.

---

# 91. Why `kill -9` Is Not the First Fix

Suppose one process uses 90 percent CPU.

Do not immediately run:

```bash
kill -9 PID
```

First determine:

* What process is it?
* Is it critical?
* Is systemd managing it?
* Will it automatically restart?
* Is it serving users?
* Is it in the middle of a transaction?
* Could termination cause corruption?
* Is high CPU expected?
* Is there a graceful termination method?

`SIGKILL` prevents the process from cleaning up.

Use it carefully.

---

# 92. Why Dropping Caches Is Not a Memory Fix

You may see online advice like:

```bash
sync
echo 3 | sudo tee /proc/sys/vm/drop_caches
```

Do not treat that as a normal solution to memory pressure.

Linux uses caches intentionally.

Dropping caches can reduce performance because the system may simply need to read the same data from storage again.

Find the real cause.
