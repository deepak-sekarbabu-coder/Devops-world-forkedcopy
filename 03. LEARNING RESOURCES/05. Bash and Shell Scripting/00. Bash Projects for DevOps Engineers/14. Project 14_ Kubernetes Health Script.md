# Project 14: Kubernetes Health Script

A Kubernetes cluster can be reachable while workloads are unhealthy.

You may have:

```text
3/3 nodes Ready
```

but still see:

```text
CrashLoopBackOff
ImagePullBackOff
Pending pods
Failed jobs
Deployments with unavailable replicas
```

In this project, we will build:

```text
k8s-health.sh
```

The script will inspect:

* Cluster nodes
* Namespaces
* Pods
* Pending pods
* CrashLoopBackOff
* ImagePullBackOff
* Failed jobs
* Deployments
* Deployment availability
* Recent warning events

Example:

```text
==========================================================================
                         KUBERNETES HEALTH
==========================================================================

Context:              production-cluster
Namespace:            production

Nodes:                3/3 Ready
Pods Running:         46
Pending Pods:         1
Problem Pods:         2
Failed Jobs:          1
Deployments Healthy:  8/9

Problems:
problem-api-77fd      CrashLoopBackOff
worker-19cd           ImagePullBackOff
payment-worker        DeploymentUnavailable

Overall Status:       CRITICAL
==========================================================================
```

The central lesson is:

```text
Kubernetes health is not one status.

You must inspect the cluster, nodes, workloads, controllers, and events together.
```

---

# 1. Real-World Scenario

Imagine VERIQTA operates workloads in:

```text
production
```

A monitoring alert says:

```text
API error rate increasing
```

You test:

```bash
kubectl get nodes
```

and see:

```text
NAME       STATUS   ROLES    AGE    VERSION
node-01    Ready    <none>   42d    v1.34.1
node-02    Ready    <none>   42d    v1.34.1
node-03    Ready    <none>   42d    v1.34.1
```

All nodes are Ready.

Does that mean Kubernetes is healthy?

No.

You run:

```bash
kubectl get pods -n production
```

and discover:

```text
NAME                              READY   STATUS             RESTARTS
problem-api-77fd                  0/1     CrashLoopBackOff   18
worker-19cd                       0/1     ImagePullBackOff   0
payments-64df                     1/1     Running            0
```

Then:

```bash
kubectl get deployments -n production
```

shows:

```text
NAME            READY   UP-TO-DATE   AVAILABLE
problem-api     0/3     3            0
payments        3/3     3            3
```

Now you have a real operational picture.

Our script will automate this first-level inspection.

# 14. Why Node Ready Matters

A NotReady node may indicate:

* Kubelet failure
* Node network problem
* Control-plane connectivity
* Resource exhaustion
* Node shutdown
* CNI problem
* Cloud instance failure

But:

```text
node NotReady
```

is still a symptom.

You need further investigation.

# 20. Pod Phases

Pods have phases such as:

```text
Pending
Running
Succeeded
Failed
Unknown
```

But the `STATUS` column from `kubectl get pods` can show more detailed container conditions such as:

```text
CrashLoopBackOff
ImagePullBackOff
ErrImagePull
ContainerCreating
Terminating
```

Do not confuse:

```text
Pod phase
```

with:

```text
displayed container status reason
```

---

# 21. Running Does Not Always Mean Ready

Example:

```text
NAME          READY   STATUS    RESTARTS
api-123       0/1     Running   0
```

The pod phase is Running.

But:

```text
READY = 0/1
```

means it is not ready to serve traffic.

This matters.

---

# 22. Readiness

Kubernetes uses readiness to determine whether a pod should receive traffic.

A pod may be:

```text
Running
```

but:

```text
NotReady
```

because:

* Readiness probe failing
* Dependency unavailable
* Application still initializing
* Application unhealthy

# 38. Failed Jobs

Jobs expose failure information.

A simple check:

```bash
kubectl get jobs \
    -A \
    -o jsonpath='{range .items[*]}{.metadata.namespace}{"\t"}{.metadata.name}{"\t"}{.status.failed}{"\n"}{end}'
```

If:

```text
status.failed > 0
```

the Job has failed pod attempts.

---

# 39. Job Failure Does Not Always Mean Final Failure

This is important.

A Job may have:

```text
status.failed=1
```

and later succeed.

So a production checker should also consider:

* Complete condition
* Failed condition
* active count
* backoff limit
* current state

For this beginner project, we will identify Jobs with failed attempts and separately identify terminal Failed condition when available.

# 52. Beginner Script

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

NAMESPACE="${1:-}"

if ! command -v kubectl >/dev/null 2>&1; then
    printf 'ERROR: kubectl is required.\n' >&2
    exit 3

    printf 'ERROR: Cannot connect to Kubernetes cluster.\n' >&2
    exit 3
fi

CONTEXT=$(
    kubectl config current-context
)

printf '%s\n' \
    "=========================================================================="

printf '%s\n' \
    "                         KUBERNETES HEALTH"

printf '%s\n' \
    "=========================================================================="

printf '\nContext: %s\n' "$CONTEXT"


if [[ -n "$NAMESPACE" ]]; then

    printf 'Namespace: %s\n\n' "$NAMESPACE"

    printf '%s\n' \
        "Pods:"

    kubectl get pods \
        -n "$NAMESPACE"

    printf '\nDeployments:\n'

    kubectl get deployments \
        -n "$NAMESPACE"

    printf '\nFailed Jobs:\n'

    kubectl get jobs \
        -n "$NAMESPACE"

    printf '\nWarning Events:\n'

    kubectl get events \
        -n "$NAMESPACE" \
        --field-selector type=Warning

else

    printf 'Namespace: ALL\n\n'

    kubectl get nodes

    printf '\nPods:\n'

    kubectl get pods -A

    printf '\nDeployments:\n'

    kubectl get deployments -A

    printf '\nJobs:\n'

    kubectl get jobs -A

    printf '\nWarning Events:\n'

    kubectl get events \
        -A \
        --field-selector type=Warning
fi
```

# 55. Production Status Model

We will use:

```text
HEALTHY
WARNING
CRITICAL
```

General policy:

## CRITICAL

Examples:

* NotReady node
* CrashLoopBackOff
* ImagePullBackOff
* ErrImagePull
* terminal Failed Job
* Deployment unavailable replicas
* Failed pod

## WARNING

Examples:

* Pending pod
* NotReady container
* Job with failed attempts but not terminally failed
* Warning events

## HEALTHY

No detected workload problems under our rules.

---

# 56. Important Limitation

These rules are intentionally general.

A real organization may classify:

```text
one Pending batch pod
```

very differently from:

```text
production API has zero available replicas
```

Production health policy should reflect service criticality.

# 57. Complete Production-Oriented Script

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

umask 077

# ------------------------------------------------------------------
# Kubernetes Health Script
# ------------------------------------------------------------------
#
# Read-only inspection utility.
#
# Exit codes:
#   0 = HEALTHY
#   1 = WARNING
#   2 = CRITICAL
#   3 = Input/configuration/kubectl error
#
# ------------------------------------------------------------------

NAMESPACE=""
SHOW_EVENTS=true

CONTEXT=""

TOTAL_NODES=0
READY_NODES=0
NOT_READY_NODES=0

RUNNING_PODS=0
PENDING_PODS=0
FAILED_PODS=0
NOT_READY_PODS=0

CRASHLOOP_COUNT=0
IMAGE_PULL_COUNT=0
OTHER_WAITING_COUNT=0

TOTAL_DEPLOYMENTS=0
HEALTHY_DEPLOYMENTS=0
UNHEALTHY_DEPLOYMENTS=0

TOTAL_JOBS=0
FAILED_JOBS=0
FAILED_JOB_ATTEMPTS=0

WARNING_EVENTS=0

OVERALL_STATUS="HEALTHY"

SCRIPT_DIR=$(
    cd -- "$(dirname -- "${BASH_SOURCE[0]}")" &&
    pwd
)

readonly SCRIPT_DIR

LOG_DIR="$SCRIPT_DIR/logs"
LOG_FILE="$LOG_DIR/k8s-health.log"

TMP_DIR=""


show_help() {

    cat <<EOF
Usage:
  $0 [options]

Options:

  --namespace NAME
      Inspect only one namespace.

  --events
      Include warning events.
      Default.

  --no-events
      Skip warning-event section.

  --help
      Show this help.

Examples:

  $0

  $0 \
    --namespace production

  $0 \
    --namespace production \
    --no-events
EOF
}


cleanup() {

    if [[ -n "${TMP_DIR:-}" &&
          -d "$TMP_DIR" ]]; then

        rm -rf -- "$TMP_DIR"
    fi
}


trap cleanup EXIT INT TERM


parse_arguments() {

    while [[ $# -gt 0 ]]; do

        case "$1" in

            --namespace)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --namespace requires a value.\n' >&2
                    exit 3
                }

                NAMESPACE="$2"
                shift 2
                ;;

            --events)

                SHOW_EVENTS=true
                shift
                ;;

            --no-events)

                SHOW_EVENTS=false
                shift
                ;;

            --help|-h)

                show_help
                exit 0
                ;;

            *)

                printf 'ERROR: Unknown option: %s\n' \
                    "$1" >&2

                exit 3
                ;;
        esac
    done
}


check_dependencies() {

    local commands=(
        kubectl
        awk
        grep
        sort
        uniq
        wc
        mktemp
        mkdir
        date
        rm
    )

    local cmd

    for cmd in "${commands[@]}"; do

        if ! command -v "$cmd" >/dev/null 2>&1; then

            printf 'ERROR: Required command missing: %s\n' \
                "$cmd" >&2

            exit 3
        fi
    done
}


check_cluster_access() {

    if ! kubectl cluster-info >/dev/null 2>&1; then

        printf '%s\n' \
            'ERROR: Cannot communicate with Kubernetes cluster.' \
            >&2

        exit 3
    fi


    CONTEXT=$(
        kubectl config current-context 2>/dev/null
    )


    if [[ -z "$CONTEXT" ]]; then

        printf 'ERROR: No current Kubernetes context.\n' >&2
        exit 3
    fi
}


validate_namespace() {

    [[ -n "$NAMESPACE" ]] || return


    if ! kubectl get namespace \
        "$NAMESPACE" \
        >/dev/null 2>&1; then

        printf 'ERROR: Namespace not found or inaccessible: %s\n' \
            "$NAMESPACE" >&2

        exit 3
    fi
}


create_temp_directory() {

    TMP_DIR=$(
        mktemp -d
    )
}


log_message() {

    local level="$1"
    local message="$2"

    mkdir -p "$LOG_DIR"

    printf '[%s] [%s] %s\n' \
        "$(date '+%Y-%m-%d %H:%M:%S')" \
        "$level" \
        "$message" \
        >> "$LOG_FILE"
}


increase_severity() {

    local new_status="$1"

    case "$new_status" in

        CRITICAL)

            OVERALL_STATUS="CRITICAL"
            ;;

        WARNING)

            if [[ "$OVERALL_STATUS" != "CRITICAL" ]]; then
                OVERALL_STATUS="WARNING"
            fi
            ;;
    esac
}


namespace_args() {

    if [[ -n "$NAMESPACE" ]]; then
        printf '%s\n' "-n" "$NAMESPACE"
    else
        printf '%s\n' "-A"
    fi
}


collect_nodes() {

    local node_file="$TMP_DIR/nodes.tsv"

    kubectl get nodes \
        -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{range .status.conditions[?(@.type=="Ready")]}{.status}{end}{"\t"}{range .status.conditions[?(@.type=="MemoryPressure")]}{.status}{end}{"\t"}{range .status.conditions[?(@.type=="DiskPressure")]}{.status}{end}{"\t"}{range .status.conditions[?(@.type=="PIDPressure")]}{.status}{end}{"\n"}{end}' \
        > "$node_file"


    while IFS=$'\t' read -r \
        node \
        ready \
        memory_pressure \
        disk_pressure \
        pid_pressure; do

        [[ -z "$node" ]] && continue

        ((TOTAL_NODES+=1))


        if [[ "$ready" == "True" ]]; then
            ((READY_NODES+=1))
        else
            ((NOT_READY_NODES+=1))
            increase_severity "CRITICAL"
        fi


        if [[ "$memory_pressure" == "True" ||
              "$disk_pressure" == "True" ||
              "$pid_pressure" == "True" ]]; then

            increase_severity "WARNING"
        fi

    done < "$node_file"
}


collect_pods() {

    local pod_file="$TMP_DIR/pods.tsv"
    local scope_args=()

    if [[ -n "$NAMESPACE" ]]; then
        scope_args=(-n "$NAMESPACE")
    else
        scope_args=(-A)
    fi


    kubectl get pods \
        "${scope_args[@]}" \
        -o jsonpath='{range .items[*]}{.metadata.namespace}{"\t"}{.metadata.name}{"\t"}{.status.phase}{"\t"}{range .status.conditions[?(@.type=="Ready")]}{.status}{end}{"\t"}{range .status.containerStatuses[*]}{.state.waiting.reason}{","}{end}{"\n"}{end}' \
        > "$pod_file"


    while IFS=$'\t' read -r \
        namespace \
        pod \
        phase \
        ready \
        waiting_reasons; do

        [[ -z "$pod" ]] && continue


        case "$phase" in

            Running)
                ((RUNNING_PODS+=1))
                ;;

            Pending)
                ((PENDING_PODS+=1))
                increase_severity "WARNING"
                ;;

            Failed)
                ((FAILED_PODS+=1))
                increase_severity "CRITICAL"
                ;;
        esac


        if [[ "$phase" == "Running" &&
              "$ready" != "True" ]]; then

            ((NOT_READY_PODS+=1))
            increase_severity "WARNING"
        fi


        if [[ "$waiting_reasons" == *"CrashLoopBackOff"* ]]; then

            ((CRASHLOOP_COUNT+=1))
            increase_severity "CRITICAL"
        fi


        if [[ "$waiting_reasons" == *"ImagePullBackOff"* ||
              "$waiting_reasons" == *"ErrImagePull"* ]]; then

            ((IMAGE_PULL_COUNT+=1))
            increase_severity "CRITICAL"
        fi


        if [[ "$waiting_reasons" =~ CreateContainerConfigError|CreateContainerError|RunContainerError ]]; then

            ((OTHER_WAITING_COUNT+=1))
            increase_severity "CRITICAL"
        fi

    done < "$pod_file"
}


collect_deployments() {

    local deployment_file="$TMP_DIR/deployments.tsv"
    local scope_args=()

    if [[ -n "$NAMESPACE" ]]; then
        scope_args=(-n "$NAMESPACE")
    else
        scope_args=(-A)
    fi


    kubectl get deployments \
        "${scope_args[@]}" \
        -o jsonpath='{range .items[*]}{.metadata.namespace}{"\t"}{.metadata.name}{"\t"}{.spec.replicas}{"\t"}{.status.availableReplicas}{"\t"}{.status.readyReplicas}{"\t"}{.status.unavailableReplicas}{"\n"}{end}' \
        > "$deployment_file"


    while IFS=$'\t' read -r \
        namespace \
        deployment \
        desired \
        available \
        ready \
        unavailable; do

        [[ -z "$deployment" ]] && continue

        ((TOTAL_DEPLOYMENTS+=1))

        desired="${desired:-0}"
        available="${available:-0}"
        ready="${ready:-0}"
        unavailable="${unavailable:-0}"


        if (( desired == 0 )); then

            ((HEALTHY_DEPLOYMENTS+=1))
            continue
        fi


        if (( available >= desired )); then

            ((HEALTHY_DEPLOYMENTS+=1))

        else

            ((UNHEALTHY_DEPLOYMENTS+=1))
            increase_severity "CRITICAL"
        fi

    done < "$deployment_file"
}


collect_jobs() {

    local jobs_file="$TMP_DIR/jobs.tsv"
    local scope_args=()

    if [[ -n "$NAMESPACE" ]]; then
        scope_args=(-n "$NAMESPACE")
    else
        scope_args=(-A)
    fi


    kubectl get jobs \
        "${scope_args[@]}" \
        -o jsonpath='{range .items[*]}{.metadata.namespace}{"\t"}{.metadata.name}{"\t"}{.status.failed}{"\t"}{range .status.conditions[?(@.type=="Failed")]}{.status}{end}{"\t"}{range .status.conditions[?(@.type=="Complete")]}{.status}{end}{"\n"}{end}' \
        > "$jobs_file"


    while IFS=$'\t' read -r \
        namespace \
        job \
        failed_attempts \
        failed_condition \
        complete_condition; do

        [[ -z "$job" ]] && continue

        ((TOTAL_JOBS+=1))

        failed_attempts="${failed_attempts:-0}"


        if [[ "$failed_condition" == "True" ]]; then

            ((FAILED_JOBS+=1))
            increase_severity "CRITICAL"

        elif (( failed_attempts > 0 )) &&
             [[ "$complete_condition" != "True" ]]; then

            ((FAILED_JOB_ATTEMPTS+=1))
            increase_severity "WARNING"
        fi

    done < "$jobs_file"
}


collect_events() {

    [[ "$SHOW_EVENTS" == true ]] || return

    local events_file="$TMP_DIR/events.txt"
    local scope_args=()

    if [[ -n "$NAMESPACE" ]]; then
        scope_args=(-n "$NAMESPACE")
    else
        scope_args=(-A)
    fi


    if kubectl get events \
        "${scope_args[@]}" \
        --field-selector type=Warning \
        --no-headers \
        > "$events_file" 2>/dev/null; then

        WARNING_EVENTS=$(
            awk 'NF {count++} END {print count+0}' \
                "$events_file"
        )
    fi
}


print_header() {

    printf '%s\n' \
        "=========================================================================="

    printf '%s\n' \
        "                         KUBERNETES HEALTH"

    printf '%s\n' \
        "=========================================================================="

    printf '\n%-24s %s\n' \
        "Context:" "$CONTEXT"

    if [[ -n "$NAMESPACE" ]]; then

        printf '%-24s %s\n' \
            "Namespace:" "$NAMESPACE"

    else

        printf '%-24s %s\n' \
            "Namespace:" "ALL"
    fi
}


print_summary() {

    printf '\n%s\n' \
        "------------------------------- SUMMARY ----------------------------------"


    printf '%-24s %s/%s Ready\n' \
        "Nodes:" \
        "$READY_NODES" \
        "$TOTAL_NODES"


    printf '%-24s %s\n' \
        "Running Pods:" "$RUNNING_PODS"


    printf '%-24s %s\n' \
        "Pending Pods:" "$PENDING_PODS"


    printf '%-24s %s\n' \
        "Failed Pods:" "$FAILED_PODS"


    printf '%-24s %s\n' \
        "Not Ready Pods:" "$NOT_READY_PODS"


    printf '%-24s %s\n' \
        "CrashLoopBackOff:" "$CRASHLOOP_COUNT"


    printf '%-24s %s\n' \
        "Image Pull Errors:" "$IMAGE_PULL_COUNT"


    printf '%-24s %s/%s\n' \
        "Deployments Healthy:" \
        "$HEALTHY_DEPLOYMENTS" \
        "$TOTAL_DEPLOYMENTS"


    printf '%-24s %s\n' \
        "Failed Jobs:" "$FAILED_JOBS"


    printf '%-24s %s\n' \
        "Jobs With Failed Attempts:" "$FAILED_JOB_ATTEMPTS"


    if [[ "$SHOW_EVENTS" == true ]]; then

        printf '%-24s %s\n' \
            "Warning Events:" "$WARNING_EVENTS"
    fi
}


print_node_problems() {

    local node_file="$TMP_DIR/nodes.tsv"
    local printed=false


    while IFS=$'\t' read -r \
        node \
        ready \
        memory_pressure \
        disk_pressure \
        pid_pressure; do

        [[ -z "$node" ]] && continue


        if [[ "$ready" != "True" ]]; then

            if [[ "$printed" == false ]]; then
                printf '\nNode Problems:\n'
                printed=true
            fi

            printf '  %-35s %s\n' \
                "$node" \
                "NotReady"
        fi


        if [[ "$memory_pressure" == "True" ]]; then

            if [[ "$printed" == false ]]; then
                printf '\nNode Problems:\n'
                printed=true
            fi

            printf '  %-35s %s\n' \
                "$node" \
                "MemoryPressure"
        fi


        if [[ "$disk_pressure" == "True" ]]; then

            if [[ "$printed" == false ]]; then
                printf '\nNode Problems:\n'
                printed=true
            fi

            printf '  %-35s %s\n' \
                "$node" \
                "DiskPressure"
        fi


        if [[ "$pid_pressure" == "True" ]]; then

            if [[ "$printed" == false ]]; then
                printf '\nNode Problems:\n'
                printed=true
            fi

            printf '  %-35s %s\n' \
                "$node" \
                "PIDPressure"
        fi

    done < "$node_file"
}


print_pod_problems() {

    local pod_file="$TMP_DIR/pods.tsv"
    local printed=false


    while IFS=$'\t' read -r \
        namespace \
        pod \
        phase \
        ready \
        waiting_reasons; do

        [[ -z "$pod" ]] && continue

        local reason=""


        if [[ "$waiting_reasons" == *"CrashLoopBackOff"* ]]; then
            reason="CrashLoopBackOff"

        elif [[ "$waiting_reasons" == *"ImagePullBackOff"* ]]; then
            reason="ImagePullBackOff"

        elif [[ "$waiting_reasons" == *"ErrImagePull"* ]]; then
            reason="ErrImagePull"

        elif [[ "$waiting_reasons" == *"CreateContainerConfigError"* ]]; then
            reason="CreateContainerConfigError"

        elif [[ "$waiting_reasons" == *"CreateContainerError"* ]]; then
            reason="CreateContainerError"

        elif [[ "$waiting_reasons" == *"RunContainerError"* ]]; then
            reason="RunContainerError"

        elif [[ "$phase" == "Pending" ]]; then
            reason="Pending"

        elif [[ "$phase" == "Failed" ]]; then
            reason="Failed"

        elif [[ "$phase" == "Running" &&
                "$ready" != "True" ]]; then
            reason="RunningNotReady"
        fi


        if [[ -n "$reason" ]]; then

            if [[ "$printed" == false ]]; then
                printf '\nPod Problems:\n'
                printf '  %-20s %-40s %s\n' \
                    "NAMESPACE" \
                    "POD" \
                    "STATUS"

                printed=true
            fi


            printf '  %-20s %-40s %s\n' \
                "$namespace" \
                "$pod" \
                "$reason"
        fi

    done < "$pod_file"
}


print_deployment_problems() {

    local deployment_file="$TMP_DIR/deployments.tsv"
    local printed=false


    while IFS=$'\t' read -r \
        namespace \
        deployment \
        desired \
        available \
        ready \
        unavailable; do

        [[ -z "$deployment" ]] && continue

        desired="${desired:-0}"
        available="${available:-0}"


        if (( desired > 0 &&
              available < desired )); then

            if [[ "$printed" == false ]]; then

                printf '\nDeployment Problems:\n'

                printf '  %-20s %-30s %-10s %-10s\n' \
                    "NAMESPACE" \
                    "DEPLOYMENT" \
                    "DESIRED" \
                    "AVAILABLE"

                printed=true
            fi


            printf '  %-20s %-30s %-10s %-10s\n' \
                "$namespace" \
                "$deployment" \
                "$desired" \
                "$available"
        fi

    done < "$deployment_file"
}


print_job_problems() {

    local jobs_file="$TMP_DIR/jobs.tsv"
    local printed=false


    while IFS=$'\t' read -r \
        namespace \
        job \
        failed_attempts \
        failed_condition \
        complete_condition; do

        [[ -z "$job" ]] && continue

        failed_attempts="${failed_attempts:-0}"

        local reason=""


        if [[ "$failed_condition" == "True" ]]; then
            reason="Failed"

        elif (( failed_attempts > 0 )) &&
             [[ "$complete_condition" != "True" ]]; then

            reason="FailedAttempts:$failed_attempts"
        fi


        if [[ -n "$reason" ]]; then

            if [[ "$printed" == false ]]; then

                printf '\nJob Problems:\n'

                printf '  %-20s %-35s %s\n' \
                    "NAMESPACE" \
                    "JOB" \
                    "STATUS"

                printed=true
            fi


            printf '  %-20s %-35s %s\n' \
                "$namespace" \
                "$job" \
                "$reason"
        fi

    done < "$jobs_file"
}


print_warning_events() {

    [[ "$SHOW_EVENTS" == true ]] || return
    (( WARNING_EVENTS > 0 )) || return


    printf '\nRecent Warning Events:\n'

    kubectl_args=()

    if [[ -n "$NAMESPACE" ]]; then
        kubectl_args=(-n "$NAMESPACE")
    else
        kubectl_args=(-A)
    fi


    kubectl get events \
        "${kubectl_args[@]}" \
        --field-selector type=Warning \
        --sort-by=.metadata.creationTimestamp \
        2>/dev/null |
        tail -n 15 || true
}


print_footer() {

    printf '\n%s\n' \
        "--------------------------------------------------------------------------"

    printf '%-24s %s\n' \
        "Overall Status:" "$OVERALL_STATUS"

    printf '%s\n' \
        "=========================================================================="
}


write_log() {

    log_message \
        "INFO" \
        "context=$CONTEXT namespace=${NAMESPACE:-ALL} nodes_ready=$READY_NODES/$TOTAL_NODES pending=$PENDING_PODS failed_pods=$FAILED_PODS crashloop=$CRASHLOOP_COUNT image_pull=$IMAGE_PULL_COUNT deployments_unhealthy=$UNHEALTHY_DEPLOYMENTS failed_jobs=$FAILED_JOBS warning_events=$WARNING_EVENTS status=$OVERALL_STATUS"
}


return_status() {

    case "$OVERALL_STATUS" in

        HEALTHY)
            return 0
            ;;

        WARNING)
            return 1
            ;;

        CRITICAL)
            return 2
            ;;

        *)
            return 3
            ;;
    esac
}


main() {

    parse_arguments "$@"

    check_dependencies

    check_cluster_access

    validate_namespace

    create_temp_directory

    collect_nodes

    collect_pods

    collect_deployments

    collect_jobs

    collect_events

    print_header

    print_summary

    print_node_problems

    print_pod_problems

    print_deployment_problems

    print_job_problems

    print_warning_events

    print_footer

    write_log

    return_status
}


main "$@"
exit $?
```

A tempting response:



* Hide the cause
* Increase blast radius
* Trigger new failures
* Disrupt healthy replicas

The script is diagnostic.

```text
wrong/missing image tag
```

not:

```text
restart Kubernetes
```

Evidence determines the next step.
