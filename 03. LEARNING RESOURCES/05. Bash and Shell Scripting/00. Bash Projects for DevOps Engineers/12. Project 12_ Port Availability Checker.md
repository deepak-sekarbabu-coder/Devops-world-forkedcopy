# Project 12: Port Availability Checker

A server can be running while a required network service is unavailable.

Examples:

```text
Server is online
SSH port 22 is blocked

Server is online
HTTPS port 443 is open

Database process is running
MySQL port 3306 is not reachable from the application server
```

This is why infrastructure troubleshooting often includes TCP connectivity testing.

In this project, we will build:

```text
port-checker.sh
```

The script will test whether remote TCP ports are reachable.

Example:

```text
server01:22      OPEN
server01:443     OPEN
server01:3306    CLOSED
```

We will test common services such as:

```text
22      SSH
80      HTTP
443     HTTPS
3306    MySQL
5432    PostgreSQL
```

You will learn:

* TCP ports
* TCP connectivity
* `nc`
* `ss`
* `timeout`
* Network troubleshooting
* DNS failures
* Connection refused
* Connection timeout
* Host and port validation
* Loops
* Arrays
* Exit codes
* Multi-host testing

The most important lesson is:

```text
A successful TCP connection proves that something accepted a connection on that port.

It does not prove that the application behind the port is healthy.
```

# 3. Understanding Ports

A port identifies a network service on a host.

Think of:

```text
IP address = building address
port       = specific door
```

A server might have:

```text
10.0.1.20
```

while different services listen on:

```text
10.0.1.20:22
10.0.1.20:80
10.0.1.20:443
```

---

# 4. Common Ports

Some common defaults:

```text
22      SSH
53      DNS
80      HTTP
443     HTTPS
3306    MySQL
5432    PostgreSQL
6379    Redis
8080    Alternative HTTP
9090    Often Prometheus or application-specific
```

These are conventional defaults.

A service can run on a different port.

Never assume:

```text
port 3306 = definitely MySQL
```

just because the port number is 3306.

---

# 5. TCP Connection Concept

A TCP connection begins with the TCP handshake.

Conceptually:

```text
Client                       Server

SYN ------------------------->

    <------------------- SYN-ACK

ACK ------------------------->

Connection established
```

If the connection succeeds:

```text
TCP path works
```

at that moment.

If it fails, possible causes include:

* DNS
* Routing
* Firewall
* Security group
* Network ACL
* Host firewall
* Service not listening
* Wrong port
* Server unavailable

---

# 6. OPEN Does Not Mean Healthy

Suppose:

```text
server01:443 OPEN
```

That proves a TCP connection was accepted.

It does not prove:

```text
HTTPS certificate valid
HTTP status 200
application healthy
database reachable
login works
```

For those checks, use application-aware tools.

Examples:

```text
443 TCP connectivity
        |
        v
curl
        |
        v
HTTP/TLS health
```

Project 10 already handled that higher layer.

---

# 7. CLOSED vs TIMEOUT

These are different.

## CLOSED / Connection Refused

Example:

```text
Connection refused
```

This often means:

```text
the destination host responded
```

but:

```text
nothing accepted the TCP connection on that port
```

Possible causes:

* Service stopped
* Wrong port
* Service bound to another interface
* Firewall actively rejecting connection

## TIMEOUT

Example:

```text
Operation timed out
```

Possible causes:

* Firewall silently dropping traffic
* Security group
* Network ACL
* Routing issue
* Host unavailable
* Network path failure

This distinction is operationally useful.

# 13. Add a Timeout

Never allow a port check to hang indefinitely.

One approach:

```bash
timeout 5 nc -z server01 443
```

This gives the check five seconds.

If `nc` itself supports connection timeout, you may also see:

```bash
nc -z -w 5 server01 443
```

But timeout flags differ between netcat implementations.

For this project, wrapping with:

```bash
timeout
```

provides a clear external limit.

---

# 14. `timeout`

Basic syntax:

```bash
timeout 5 command
```

Example:

```bash
timeout 5 nc -z server01 443
```

If the command exceeds five seconds, `timeout` terminates it.

---

# 15. `timeout` Exit Code

GNU `timeout` commonly returns:

```text
124
```

when its timeout expires.

That lets us distinguish:

```text
connection attempt failed quickly
```

from:

```text
connection did not finish before timeout
```

# 27. Validate Port Numbers

TCP ports range from:

```text
1
```

to:

```text
65535
```

Port:

```text
0
```

is reserved and should not be used as a normal destination service port.

Validation:

```bash
if [[ ! "$PORT" =~ ^[0-9]+$ ]]; then
    echo "Invalid port"
fi
```

Then:

```bash
if (( PORT < 1 || PORT > 65535 )); then
    echo "Port out of range"
fi
```

# 30. Status Model

We will use:

```text
OPEN
CLOSED
TIMEOUT
DNS_FAILED
ERROR
```

Meaning:

## OPEN

TCP connection succeeded.

## CLOSED

Destination responded but TCP connection was not accepted, or `nc` failed quickly.

## TIMEOUT

Check exceeded the allowed time.

## DNS_FAILED

Hostname could not be resolved.

## ERROR

Script or dependency problem.

This would be misleading:

```text

```

when the actual problem is:

```text
DNS_FAILED
```

or:

```text
TIMEOUT
```

Good operational tools report what they actually know.

# 32. Complete Beginner Version

Create:

```bash
nano port-checker.sh
```

Add:

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

HOST="${1:-}"
PORT="${2:-}"

TIMEOUT_SECONDS=5


if [[ -z "$HOST" || -z "$PORT" ]]; then

    printf 'Usage: %s HOST PORT\n' "$0"
    exit 3
fi


if [[ ! "$PORT" =~ ^[0-9]+$ ]]; then

    printf 'ERROR: Port must be numeric.\n' >&2
    exit 3
fi


if (( PORT < 1 || PORT > 65535 )); then

    printf 'ERROR: Port must be between 1 and 65535.\n' >&2
    exit 3
fi


if ! command -v nc >/dev/null 2>&1; then

    printf 'ERROR: nc is required.\n' >&2
    exit 3
fi


if ! command -v timeout >/dev/null 2>&1; then

    printf 'ERROR: timeout is required.\n' >&2
    exit 3
fi


if ! getent hosts "$HOST" >/dev/null 2>&1; then

    printf '%s:%s\tDNS_FAILED\n' \
        "$HOST" \
        "$PORT"

    exit 2
fi


timeout "$TIMEOUT_SECONDS" \
    nc -z "$HOST" "$PORT" \
    >/dev/null 2>&1

STATUS=$?


case "$STATUS" in

    0)

        printf '%s:%s\tOPEN\n' \
            "$HOST" \
            "$PORT"

        exit 0
        ;;

    124)

        printf '%s:%s\tTIMEOUT\n' \
            "$HOST" \
            "$PORT"

        exit 2
        ;;

    *)

        printf '%s:%s\tCLOSED\n' \
            "$HOST" \
            "$PORT"

        exit 1
        ;;
esac
```

```bash

```

```text

```


* Configuration issue
* Different port
* Unix socket only
* Process unhealthy

This shows why:

```text

```


# 42. Port Open Locally but Closed Remotely

Suppose on the database server:

```bash
ss -lnt | grep ':3306 '
```

shows:

```text
LISTEN ... 127.0.0.1:3306
```

From the application server:

```text
database01:3306 CLOSED
```

Likely cause:

```text
database bound only to localhost
```

The service must listen on an appropriate interface if remote access is intended.

Do not simply bind databases to every interface without considering security.

# 44. Port Closed vs Firewall Drop

Typical behavior:

```text
Connection refused
```

often suggests:

```text
reachable host, port not accepting
```

while:

```text
timeout
```

often suggests:

```text
traffic dropped or path unavailable
```

This is a useful heuristic.

It is not an absolute universal rule.

Network devices can behave differently.

---

In cloud environments, the Linux server may be configured correctly while cloud-level networking blocks the port.

Example:

```text

       |
       X
       |

```

Investigate:

```text

port
protocol

```

---

# 47. Database Security Principle

Do not make:

```text
3306
```

or:

```text
5432
```

publicly accessible just because connectivity is failing.

A safer architecture is often:

```text
application security group
         |
         v
database security group
```

with database access limited to approved application sources.

# 51. Production Script

Replace the beginner script with:

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

umask 077

# ------------------------------------------------------------------
# Port Availability Checker
# ------------------------------------------------------------------
#
# Exit codes:
#   0 = All checked ports OPEN
#   1 = One or more ports CLOSED
#   2 = One or more TIMEOUT / DNS failures
#   3 = Input/configuration error
#
# ------------------------------------------------------------------

HOST=""
PORTS=""

INVENTORY_FILE=""

TIMEOUT_SECONDS=5

TOTAL_CHECKS=0
OPEN_COUNT=0
CLOSED_COUNT=0
TIMEOUT_COUNT=0
DNS_FAILED_COUNT=0

OVERALL_STATUS="HEALTHY"

SCRIPT_DIR=$(
    cd -- "$(dirname -- "${BASH_SOURCE[0]}")" &&
    pwd
)

readonly SCRIPT_DIR

LOG_DIR="$SCRIPT_DIR/logs"
LOG_FILE="$LOG_DIR/port-checker.log"


show_help() {

    cat <<EOF
Usage:

Single host:
  $0 --host HOST --ports PORT1,PORT2,...

Inventory:
  $0 --inventory FILE

Options:
  --host HOST          Hostname or IP address

  --ports LIST         Comma-separated TCP ports

  --inventory FILE     CSV file containing host,port

  --timeout N          Per-check timeout in seconds
                       Default: 5

  --help               Display this help

Examples:
  $0 \
    --host server01 \
    --ports 22,80,443

  $0 \
    --host database01 \
    --ports 3306,5432 \
    --timeout 3

  $0 \
    --inventory ports.csv
EOF
}


is_integer() {
    [[ "$1" =~ ^[0-9]+$ ]]
}


validate_port() {

    local port="$1"

    if ! is_integer "$port"; then

        printf 'ERROR: Invalid port: %s\n' \
            "$port" >&2

        return 1
    fi

    if (( port < 1 || port > 65535 )); then

        printf 'ERROR: Port out of range: %s\n' \
            "$port" >&2

        return 1
    fi

    return 0
}


parse_arguments() {

    while [[ $# -gt 0 ]]; do

        case "$1" in

            --host)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --host requires a value.\n' >&2
                    exit 3
                }

                HOST="$2"
                shift 2
                ;;

            --ports)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --ports requires a value.\n' >&2
                    exit 3
                }

                PORTS="$2"
                shift 2
                ;;

            --inventory)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --inventory requires a file.\n' >&2
                    exit 3
                }

                INVENTORY_FILE="$2"
                shift 2
                ;;

            --timeout)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --timeout requires a value.\n' >&2
                    exit 3
                }

                if ! is_integer "$2" ||
                   (( $2 < 1 || $2 > 120 )); then

                    printf 'ERROR: Timeout must be between 1 and 120 seconds.\n' \
                        >&2

                    exit 3
                fi

                TIMEOUT_SECONDS="$2"
                shift 2
                ;;

            --help|-h)

                show_help
                exit 0
                ;;

            *)

                printf 'ERROR: Unknown option: %s\n' \
                    "$1" >&2

                exit 3
                ;;
        esac

    done
}


check_dependencies() {

    local commands=(
        nc
        timeout
        getent
        date
        mkdir
    )

    local cmd

    for cmd in "${commands[@]}"; do

        if ! command -v "$cmd" >/dev/null 2>&1; then

            printf 'ERROR: Required command missing: %s\n' \
                "$cmd" >&2

            exit 3
        fi

    done
}


validate_inputs() {

    if [[ -n "$INVENTORY_FILE" ]]; then

        if [[ -n "$HOST" || -n "$PORTS" ]]; then

            printf 'ERROR: Use either --inventory or --host/--ports, not both.\n' \
                >&2

            exit 3
        fi

        if [[ ! -f "$INVENTORY_FILE" ]]; then

            printf 'ERROR: Inventory file not found: %s\n' \
                "$INVENTORY_FILE" >&2

            exit 3
        fi

        if [[ ! -r "$INVENTORY_FILE" ]]; then

            printf 'ERROR: Inventory file is not readable: %s\n' \
                "$INVENTORY_FILE" >&2

            exit 3
        fi

        return
    fi


    if [[ -z "$HOST" ]]; then

        printf 'ERROR: --host is required.\n' >&2
        exit 3
    fi


    if [[ -z "$PORTS" ]]; then

        printf 'ERROR: --ports is required.\n' >&2
        exit 3
    fi
}


log_message() {

    local level="$1"
    local message="$2"

    mkdir -p "$LOG_DIR"

    printf '[%s] [%s] %s\n' \
        "$(date '+%Y-%m-%d %H:%M:%S')" \
        "$level" \
        "$message" \
        >> "$LOG_FILE"
}


get_service_name() {

    local port="$1"

    case "$port" in

        22)
            printf 'SSH'
            ;;

        53)
            printf 'DNS'
            ;;

        80)
            printf 'HTTP'
            ;;

        443)
            printf 'HTTPS'
            ;;

        3306)
            printf 'MySQL'
            ;;

        5432)
            printf 'PostgreSQL'
            ;;

        6379)
            printf 'Redis'
            ;;

        8080)
            printf 'HTTP-Alt'
            ;;

        9090)
            printf 'App/Prometheus'
            ;;

        *)
            printf 'Unknown'
            ;;
    esac
}


host_resolves() {

    local host="$1"

    getent hosts "$host" \
        >/dev/null 2>&1
}


update_overall_status() {

    local status="$1"

    case "$status" in

        TIMEOUT|DNS_FAILED)

            OVERALL_STATUS="CRITICAL"
            ;;

        CLOSED)

            if [[ "$OVERALL_STATUS" != "CRITICAL" ]]; then
                OVERALL_STATUS="WARNING"
            fi
            ;;
    esac
}


check_port() {

    local host="$1"
    local port="$2"

    local status
    local service
    local nc_status

    ((TOTAL_CHECKS+=1))

    service=$(get_service_name "$port")


    if ! host_resolves "$host"; then

        status="DNS_FAILED"

        ((DNS_FAILED_COUNT+=1))

        update_overall_status "$status"

        printf '%-20s %-9s %-15s %-15s\n' \
            "$host" \
            "$port" \
            "$service" \
            "$status"

        log_message \
            "ERROR" \
            "host=$host port=$port service=$service status=$status"

        return
    fi


    timeout \
        "$TIMEOUT_SECONDS" \
        nc -z "$host" "$port" \
        >/dev/null 2>&1

    nc_status=$?


    case "$nc_status" in

        0)

            status="OPEN"

            ((OPEN_COUNT+=1))
            ;;

        124)

            status="TIMEOUT"

            ((TIMEOUT_COUNT+=1))
            ;;

        *)

            status="CLOSED"

            ((CLOSED_COUNT+=1))
            ;;
    esac


    update_overall_status "$status"


    printf '%-20s %-9s %-15s %-15s\n' \
        "$host" \
        "$port" \
        "$service" \
        "$status"


    if [[ "$status" == "OPEN" ]]; then

        log_message \
            "INFO" \
            "host=$host port=$port service=$service status=$status"

    else

        log_message \
            "WARNING" \
            "host=$host port=$port service=$service status=$status"
    fi
}


process_single_host() {

    local port
    local -a port_array=()

    IFS=',' read -r -a port_array \
        <<< "$PORTS"


    for port in "${port_array[@]}"; do

        port="${port#"${port%%[![:space:]]*}"}"
        port="${port%"${port##*[![:space:]]}"}"

        if ! validate_port "$port"; then
            exit 3
        fi

        check_port \
            "$HOST" \
            "$port"
    done
}


process_inventory() {

    local host
    local port
    local line_number=0

    while IFS=',' read -r host port ||
          [[ -n "$host" || -n "$port" ]]; do

        ((line_number+=1))

        host="${host#"${host%%[![:space:]]*}"}"
        host="${host%"${host##*[![:space:]]}"}"

        port="${port#"${port%%[![:space:]]*}"}"
        port="${port%"${port##*[![:space:]]}"}"


        [[ -z "$host" && -z "$port" ]] && continue


        if (( line_number == 1 )) &&
           [[ "$host" == "host" &&
              "$port" == "port" ]]; then

            continue
        fi


        if [[ "$host" =~ ^# ]]; then
            continue
        fi


        if [[ -z "$host" || -z "$port" ]]; then

            printf 'ERROR: Invalid inventory row %s.\n' \
                "$line_number" >&2

            exit 3
        fi


        if ! validate_port "$port"; then

            printf 'ERROR: Invalid port on inventory row %s.\n' \
                "$line_number" >&2

            exit 3
        fi


        check_port \
            "$host" \
            "$port"

    done < "$INVENTORY_FILE"
}


print_header() {

    printf '%s\n' \
        "=========================================================================="

    printf '%s\n' \
        "                     PORT AVAILABILITY REPORT"

    printf '%s\n' \
        "=========================================================================="

    printf '\n%-20s %-9s %-15s %-15s\n' \
        "HOST" \
        "PORT" \
        "SERVICE" \
        "STATUS"

    printf '%s\n' \
        "--------------------------------------------------------------------------"
}


print_summary() {

    printf '\n%s\n' \
        "--------------------------------------------------------------------------"

    printf '%-24s %s\n' \
        "Total Checks:" "$TOTAL_CHECKS"

    printf '%-24s %s\n' \
        "Open:" "$OPEN_COUNT"

    printf '%-24s %s\n' \
        "Closed:" "$CLOSED_COUNT"

    printf '%-24s %s\n' \
        "Timeout:" "$TIMEOUT_COUNT"

    printf '%-24s %s\n' \
        "DNS Failed:" "$DNS_FAILED_COUNT"

    printf '\n%-24s %s\n' \
        "Overall Status:" "$OVERALL_STATUS"

    printf '%s\n' \
        "=========================================================================="
}


return_status() {

    if (( TIMEOUT_COUNT > 0 ||
          DNS_FAILED_COUNT > 0 )); then

        return 2
    fi


    if (( CLOSED_COUNT > 0 )); then

        return 1
    fi


    return 0
}


main() {

    parse_arguments "$@"

    check_dependencies

    validate_inputs

    print_header


    if [[ -n "$INVENTORY_FILE" ]]; then

        process_inventory

    else

        process_single_host
    fi


    print_summary


    log_message \
        "INFO" \
        "run_complete total=$TOTAL_CHECKS open=$OPEN_COUNT closed=$CLOSED_COUNT timeout=$TIMEOUT_COUNT dns_failed=$DNS_FAILED_COUNT overall=$OVERALL_STATUS"


    return_status
}


main "$@"
exit $?
```
