# Project 19: Configuration Backup Script

## Real-World Configuration Protection, Validation, and Change Detection for DevOps Engineers

Production incidents often begin with a sentence like:

```text
Something changed.
```

Maybe someone changed:

```text
/etc/nginx/nginx.conf
/etc/ssh/sshd_config
/etc/docker/daemon.json
/etc/systemd/system/
application configuration
```

The service fails.

The engineer asks:

```text
What was the previous configuration?
```

And nobody knows.

That is exactly the operational problem this project solves.

We will build:

```text
config-backup.sh
```

The script will:

* Discover configuration files
* Validate configured paths
* Create timestamped backups
* Preserve directory structure
* Generate SHA-256 checksums
* Create file manifests
* Verify archive integrity
* Compare backups
* Detect added files
* Detect removed files
* Detect modified files
* Generate configuration change reports
* Protect sensitive configuration
* Apply backup retention
* Support restore testing
* Never automatically overwrite production configuration

Example:

```text
==========================================================================
                    CONFIGURATION BACKUP REPORT
==========================================================================

Backup ID:              2026-09-11-105500
Sources:                5
Files Backed Up:        42

config-backup-2026-09-11-105500.tar.gz

```

The central production lesson is:

```text
A backup is not useful merely because an archive file exists.

You need to know what it contains, whether it is intact, what changed, and whether it can be restored.
```

# 7. `tar`

GNU `tar` creates archives by combining files and directories into an archive. It can also verify archives against filesystem contents in supported situations.

Basic example:

```bash
tar \
    -czf \
    config-backup.tar.gz \
    /etc/nginx
```

Options:

```text
-c    create archive
-z    gzip compression
-f    archive filename follows
```

---

# 8. Absolute Path Warning

If you run:

```bash
tar -czf backup.tar.gz /etc/nginx
```

GNU tar normally removes the leading `/` from member names.

That means inside the archive you may see:

```text
etc/nginx/nginx.conf
```

rather than:

```text
/etc/nginx/nginx.conf
```

This is useful because extraction does not automatically target absolute filesystem locations.

That is a safety advantage.

---

# 9. Never Restore Directly Into `/`

Do not begin restore testing with:

```bash
sudo tar -xzf backup.tar.gz -C /
```

That can overwrite live production configuration.

Instead:

```text
restore into a temporary directory
```

first.

Example:

```bash
mkdir restore-test

tar \
    -xzf backup.tar.gz \
    -C restore-test
```

Inspect the files.

Then decide what should actually be restored.

# 14. Sensitive Configuration


# 15. Compression Is Not Encryption

This:

```text
backup.tar.gz
```

is compressed.

It is not encrypted.

Anyone who can read the archive can read its contents.

Do not confuse:

```text
gzip
```

with:

```text
encryption.
```

# 20. `tar --verify`

GNU tar also supports `--verify` to compare stored archive members against filesystem files after writing under supported conditions.

This is valuable.

But our production backup will also perform independent checks:

```text
archive readable
manifest present
checksum generated
restore test possible
```

because a robust backup strategy should not depend on one verification mechanism alone.

# 21. SHA-256 Checksums

After backup:

```bash
sha256sum \
    config-backup.tar.gz
```

Example:

```text
9fba63b9...  config-backup.tar.gz
```

This fingerprint lets us detect archive corruption or modification later.

---

# 22. Store Checksum

Use:

```bash
sha256sum \
    config-backup.tar.gz \
    > config-backup.tar.gz.sha256
```

Verify later:

```bash
sha256sum \
    -c config-backup.tar.gz.sha256
```

Expected:

```text
config-backup.tar.gz: OK
```

# 24. File-Level Checksums

Archive checksum tells us:

```text
Did the archive file change?
```

But file-level checksums tell us:

```text
Which configuration files changed?
```

Example:

```bash
find \
    /etc/nginx \
    -type f \
    -exec sha256sum {} \;
```

Result:

```text
abc123... /etc/nginx/nginx.conf
def456... /etc/nginx/mime.types
```

# 25. Manifest Concept

Every backup should contain a manifest.

Example:

```text
MANIFEST.sha256
```

containing:

```text

checksum    relative/path
checksum    relative/path
```

This provides a configuration fingerprint.

# 29. `diff`

GNU Diffutils provides tools for comparing files and directories. `diff` can show differences between files or recursively compare directory trees.

Example:

```bash
diff \
    old/nginx.conf \
    new/nginx.conf
```

---

# 30. Unified Diff

Use:

```bash
diff \
    -u \
    old/nginx.conf \
    new/nginx.conf
```

Example:

```diff
--- old/nginx.conf
+++ new/nginx.conf
@@
-listen 80;
+listen 8080;
```

This is much easier to read.

---

# 31. Recursive Directory Comparison

Use:

```bash
diff \
    -ruN \
    previous/etc/nginx \
    current/etc/nginx
```

Where:

```text
-r    recursive
-u    unified diff
-N    treat missing files as empty
```

This can reveal additions, removals, and modifications.

---

# 32. Why Diff Reports Can Be Sensitive

Imagine:

```diff
-DATABASE_PASSWORD=old-secret
+DATABASE_PASSWORD=new-secret
```

A raw diff has now exposed both secrets.

Therefore production change reports must be treated as sensitive.

Do not automatically:

```text
email raw diff
post it to Slack
upload to public CI artifacts
commit it to GitHub
```

---

# 33. Safer Change Summary

For routine monitoring, prefer:

```text
MODIFIED:
opt/veriqta/config/database.conf
```

rather than automatically printing its content.

Then engineers can inspect the detailed diff intentionally.

# 38. Why We Use a Staging Directory

Instead of directly archiving live files into the final archive, we create:

```text
temporary staging directory
```

Then:

```text
copy configuration
generate manifests
archive staging directory
```

This creates a consistent backup unit.

It also allows us to include:

```text
backup metadata
checksums

```

inside the archive itself.

---

# 39. Race Condition Awareness

Configuration can change while the backup runs.

Example:

```text
10:00:00 nginx.conf copied
10:00:01 nginx.conf changed
10:00:02 other files copied
```

Your archive is now a point-in-time approximation, not a transactional snapshot.

For ordinary configuration files this may be acceptable.

For databases and highly dynamic state:

```text
use application-aware backup mechanisms.
```

# 40. Complete Production-Oriented Script

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

umask 077

# ------------------------------------------------------------------
# Configuration Backup Script
# ------------------------------------------------------------------
#
# Exit codes:
#
#   0 = successful backup
#   1 = successful backup with warning
#   2 = backup/verification failure
#   3 = configuration/dependency error
#   4 = restore-test failure
#
# ------------------------------------------------------------------

BACKUP_DIR="./backups"
REPORT_DIR="./reports"

RETENTION_DAYS=30

COMPARE_PREVIOUS=true
DETAILED_DIFF=false

RESTORE_TEST_ARCHIVE=""

declare -a CONFIG_PATHS=()

WARNINGS=0

TIMESTAMP=""
BACKUP_ID=""
ARCHIVE=""
CHECKSUM_FILE=""

STAGING_ROOT=""
PAYLOAD_ROOT=""

TMP_DIR=""

SCRIPT_DIR=$(
    cd -- "$(dirname -- "${BASH_SOURCE[0]}")" &&
    pwd
)

readonly SCRIPT_DIR

LOG_DIR="$SCRIPT_DIR/logs"
LOG_FILE="$LOG_DIR/config-backup.log"

CHECKSUM_COMMAND=""


show_help() {

    cat <<EOF
Usage:

  $0 [options]

Backup source options:

  --path PATH
      Add configuration file or directory.
      May be supplied multiple times.

Backup options:

  --backup-dir DIR
      Destination for backup archives.
      Default: ./backups

  --report-dir DIR
      Destination for change reports.
      Default: ./reports

  --retention-days N
      Delete successful backup sets older than N days.
      Default: 30

  --no-compare
      Do not compare with previous backup.

  --detailed-diff
      Produce detailed recursive diff.
      WARNING: diff may expose sensitive values.

Restore validation:

  --restore-test ARCHIVE
      Extract ARCHIVE to a temporary directory
      and validate the included file manifest.

Other:

  --help
      Show help.

Examples:

  $0

  $0 \
    --path /etc/nginx \
    --path /etc/ssh

  $0 \
    --backup-dir /var/backups/veriqta-config \
    --retention-days 60

  $0 \
    --detailed-diff

  $0 \
    --restore-test \
    backups/config-backup-2026-09-11-105500.tar.gz
EOF
}


cleanup() {

    if [[ -n "${TMP_DIR:-}" &&
          -d "$TMP_DIR" ]]; then

        rm -rf -- "$TMP_DIR"
    fi
}


trap cleanup EXIT INT TERM


is_nonnegative_integer() {

    [[ "$1" =~ ^[0-9]+$ ]]
}


parse_arguments() {

    while [[ $# -gt 0 ]]; do

        case "$1" in

            --path)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --path requires a value.\n' >&2
                    exit 3
                }

                CONFIG_PATHS+=("$2")
                shift 2
                ;;

            --backup-dir)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --backup-dir requires a value.\n' >&2
                    exit 3
                }

                BACKUP_DIR="$2"
                shift 2
                ;;

            --report-dir)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --report-dir requires a value.\n' >&2
                    exit 3
                }

                REPORT_DIR="$2"
                shift 2
                ;;

            --retention-days)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --retention-days requires a value.\n' >&2
                    exit 3
                }

                RETENTION_DAYS="$2"
                shift 2
                ;;

            --no-compare)

                COMPARE_PREVIOUS=false
                shift
                ;;

            --detailed-diff)

                DETAILED_DIFF=true
                shift
                ;;

            --restore-test)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --restore-test requires an archive.\n' >&2
                    exit 3
                }

                RESTORE_TEST_ARCHIVE="$2"
                shift 2
                ;;

            --help|-h)

                show_help
                exit 0
                ;;

            *)

                printf 'ERROR: Unknown option: %s\n' \
                    "$1" >&2

                exit 3
                ;;
        esac
    done
}


set_default_paths() {

    if (( ${#CONFIG_PATHS[@]} > 0 )); then
        return
    fi


    CONFIG_PATHS=(
        "/etc/nginx"
        "/etc/ssh"
        "/etc/systemd"
        "/etc/docker"
        "/opt/veriqta/config"
    )
}


check_dependencies() {

    local commands=(
        tar
        find
        diff
        stat
        cp
        mkdir
        mktemp
        date
        awk
        sort
        comm
        wc
        rm
        dirname
        basename
    )

    local cmd


    for cmd in "${commands[@]}"; do

        if ! command -v "$cmd" >/dev/null 2>&1; then

            printf 'ERROR: Required command missing: %s\n' \
                "$cmd" >&2

            exit 3
        fi

    done


    if command -v sha256sum >/dev/null 2>&1; then

        CHECKSUM_COMMAND="sha256sum"

    elif command -v shasum >/dev/null 2>&1; then

        CHECKSUM_COMMAND="shasum"

    else

        printf '%s\n' \
            'ERROR: sha256sum or shasum is required.' \
            >&2

        exit 3
    fi
}


validate_configuration() {

    if ! is_nonnegative_integer "$RETENTION_DAYS"; then

        printf '%s\n' \
            'ERROR: retention days must be a non-negative integer.' \
            >&2

        exit 3
    fi


    if [[ -n "$RESTORE_TEST_ARCHIVE" ]]; then

        if [[ ! -f "$RESTORE_TEST_ARCHIVE" ]]; then

            printf 'ERROR: Archive not found: %s\n' \
                "$RESTORE_TEST_ARCHIVE" >&2

            exit 3
        fi
    fi
}


log_message() {

    local level="$1"
    local message="$2"

    mkdir -p "$LOG_DIR"

    printf '[%s] [%s] %s\n' \
        "$(date -u '+%Y-%m-%d %H:%M:%S UTC')" \
        "$level" \
        "$message" \
        >> "$LOG_FILE"
}


checksum_file() {

    local file="$1"

    if [[ "$CHECKSUM_COMMAND" == "sha256sum" ]]; then

        sha256sum "$file"

    else

        shasum \
            -a 256 \
            "$file"
    fi
}


checksum_only() {

    local file="$1"

    checksum_file "$file" |
    awk '{print $1}'
}


initialize_backup() {

    TIMESTAMP=$(
        date -u '+%Y-%m-%d-%H%M%S'
    )

    BACKUP_ID="$TIMESTAMP"


    mkdir -p \
        "$BACKUP_DIR" \
        "$REPORT_DIR"


    TMP_DIR=$(
        mktemp -d
    )


    STAGING_ROOT="$TMP_DIR/config-backup-$BACKUP_ID"

    PAYLOAD_ROOT="$STAGING_ROOT/payload"


    mkdir -p \
        "$PAYLOAD_ROOT"


    ARCHIVE="$BACKUP_DIR/config-backup-$BACKUP_ID.tar.gz"

    CHECKSUM_FILE="$ARCHIVE.sha256"
}


validate_sources() {

    local path
    local valid_count=0


    for path in "${CONFIG_PATHS[@]}"; do

        if [[ -e "$path" || -L "$path" ]]; then

            ((valid_count+=1))

            printf 'SOURCE OK: %s\n' \
                "$path"

        else

            ((WARNINGS+=1))

            printf 'WARNING: Config path missing: %s\n' \
                "$path" >&2

            log_message \
                "WARNING" \
                "source_missing path=$path"
        fi

    done


    if (( valid_count == 0 )); then

        printf '%s\n' \
            'ERROR: None of the configured backup paths exist.' \
            >&2

        exit 3
    fi
}


copy_source() {

    local source="$1"

    [[ -e "$source" || -L "$source" ]] || return


    local relative

    relative="${source#/}"


    local parent

    parent=$(
        dirname \
            "$PAYLOAD_ROOT/$relative"
    )


    mkdir -p \
        "$parent"


    if ! cp \
        -a \
        "$source" \
        "$PAYLOAD_ROOT/$relative"; then

        printf 'ERROR: Failed to copy source: %s\n' \
            "$source" >&2

        log_message \
            "ERROR" \
            "copy_failed source=$source"

        exit 2
    fi
}


copy_sources() {

    local path


    for path in "${CONFIG_PATHS[@]}"; do

        copy_source \
            "$path"
    done
}


create_content_manifest() {

    local manifest="$STAGING_ROOT/MANIFEST.sha256"


    : > "$manifest"


    while IFS= read -r -d '' file; do

        local relative
        local checksum

        relative="${file#"$PAYLOAD_ROOT/"}"

        checksum=$(
            checksum_only \
                "$file"
        )


        printf '%s  %s\n' \
            "$checksum" \
            "$relative" \
            >> "$manifest"

    done < <(
        find \
            "$PAYLOAD_ROOT" \
            -type f \
            -print0 |
        sort -z
    )
}


create_metadata_manifest() {

    local manifest="$STAGING_ROOT/METADATA.tsv"


    printf '%s\t%s\t%s\t%s\t%s\t%s\t%s\n' \
        "TYPE" \
        "MODE" \
        "OWNER" \
        "GROUP" \
        "SIZE" \
        "MTIME" \
        "PATH" \
        > "$manifest"


    while IFS= read -r -d '' item; do

        local relative
        local metadata

        relative="${item#"$PAYLOAD_ROOT/"}"


        if metadata=$(
            stat \
                -c '%F	%a	%U	%G	%s	%Y' \
                "$item" \
                2>/dev/null
        ); then

            printf '%s\t%s\n' \
                "$metadata" \
                "$relative" \
                >> "$manifest"

        else

            # macOS/BSD stat fallback.
            metadata=$(
                stat \
                    -f '%HT	%Lp	%Su	%Sg	%z	%m' \
                    "$item"
            )

            printf '%s\t%s\n' \
                "$metadata" \
                "$relative" \
                >> "$manifest"
        fi

    done < <(
        find \
            "$PAYLOAD_ROOT" \
            -mindepth 1 \
            -print0 |
        sort -z
    )
}


create_backup_metadata() {

    local metadata_file="$STAGING_ROOT/BACKUP-INFO.txt"


    {
        printf 'Backup ID: %s\n' \
            "$BACKUP_ID"

        printf 'Created UTC: %s\n' \
            "$(date -u '+%Y-%m-%d %H:%M:%S UTC')"

        printf 'Host: %s\n' \
            "$(hostname)"

        printf '\nSources:\n'


        local path

        for path in "${CONFIG_PATHS[@]}"; do

            printf '%s\n' \
                "$path"
        done

    } > "$metadata_file"
}


create_archive() {

    if ! tar \
        -C "$TMP_DIR" \
        -czf "$ARCHIVE" \
        "config-backup-$BACKUP_ID"; then

        printf '%s\n' \
            'ERROR: Archive creation failed.' \
            >&2

        log_message \
            "ERROR" \
            "archive_creation_failed"

        exit 2
    fi


    log_message \
        "INFO" \
        "archive_created path=$ARCHIVE"
}


verify_archive_readable() {

    if ! tar \
        -tzf "$ARCHIVE" \
        >/dev/null; then

        printf '%s\n' \
            'ERROR: Archive validation failed.' \
            >&2

        log_message \
            "ERROR" \
            "archive_validation_failed"

        exit 2
    fi
}


generate_archive_checksum() {

    local checksum

    checksum=$(
        checksum_only \
            "$ARCHIVE"
    )


    printf '%s  %s\n' \
        "$checksum" \
        "$(basename "$ARCHIVE")" \
        > "$CHECKSUM_FILE"


    log_message \
        "INFO" \
        "archive_checksum=$checksum"
}


verify_archive_checksum() {

    local expected
    local actual


    expected=$(
        awk '{print $1}' \
            "$CHECKSUM_FILE"
    )


    actual=$(
        checksum_only \
            "$ARCHIVE"
    )


    if [[ "$expected" != "$actual" ]]; then

        printf '%s\n' \
            'ERROR: Archive checksum verification failed.' \
            >&2

        exit 2
    fi
}


restore_archive_to_temp() {

    local archive="$1"
    local destination="$2"


    mkdir -p \
        "$destination"


    if ! tar \
        -xzf "$archive" \
        -C "$destination"; then

        return 1
    fi


    return 0
}


verify_restored_manifest() {

    local extracted_root="$1"

    local backup_root

    backup_root=$(
        find \
            "$extracted_root" \
            -mindepth 1 \
            -maxdepth 1 \
            -type d |
        head -n 1
    )


    if [[ -z "$backup_root" ]]; then
        return 1
    fi


    local payload="$backup_root/payload"
    local manifest="$backup_root/MANIFEST.sha256"


    if [[ ! -d "$payload" ||
          ! -f "$manifest" ]]; then

        return 1
    fi


    while IFS= read -r line; do

        [[ -z "$line" ]] && continue

        local expected
        local relative
        local file
        local actual


        expected="${line%%  *}"
        relative="${line#*  }"

        file="$payload/$relative"


        if [[ ! -f "$file" ]]; then

            printf 'MISSING: %s\n' \
                "$relative" >&2

            return 1
        fi


        actual=$(
            checksum_only \
                "$file"
        )


        if [[ "$expected" != "$actual" ]]; then

            printf 'CHECKSUM MISMATCH: %s\n' \
                "$relative" >&2

            return 1
        fi

    done < "$manifest"


    return 0
}


perform_restore_test() {

    local archive="$1"

    local restore_dir="$TMP_DIR/restore-test"


    printf 'Testing archive restore: %s\n' \
        "$archive"


    if ! restore_archive_to_temp \
        "$archive" \
        "$restore_dir"; then

        printf '%s\n' \
            'ERROR: Archive extraction failed during restore test.' \
            >&2

        return 4
    fi


    if ! verify_restored_manifest \
        "$restore_dir"; then

        printf '%s\n' \
            'ERROR: Restored files failed manifest validation.' \
            >&2

        return 4
    fi


    printf '%s\n' \
        'Restore test: PASSED'

    return 0
}


find_previous_archive() {

    find \
        "$BACKUP_DIR" \
        -maxdepth 1 \
        -type f \
        -name 'config-backup-*.tar.gz' \
        ! -name "$(basename "$ARCHIVE")" \
        -print |
    sort |
    tail -n 1
}


extract_backup() {

    local archive="$1"
    local destination="$2"

    mkdir -p \
        "$destination"

    tar \
        -xzf "$archive" \
        -C "$destination"
}


find_extracted_backup_root() {

    local directory="$1"

    find \
        "$directory" \
        -mindepth 1 \
        -maxdepth 1 \
        -type d |
    head -n 1
}


create_change_report() {

    [[ "$COMPARE_PREVIOUS" == true ]] || return


    local previous_archive

    previous_archive=$(
        find_previous_archive
    )


    if [[ -z "$previous_archive" ]]; then

        printf '%s\n' \
            'No previous backup available for comparison.'

        return
    fi


    local previous_dir="$TMP_DIR/previous"
    local current_dir="$TMP_DIR/current"


    if ! extract_backup \
        "$previous_archive" \
        "$previous_dir"; then

        printf '%s\n' \
            'WARNING: Could not extract previous backup.' \
            >&2

        ((WARNINGS+=1))

        return
    fi


    if ! extract_backup \
        "$ARCHIVE" \
        "$current_dir"; then

        printf '%s\n' \
            'WARNING: Could not extract current backup for comparison.' \
            >&2

        ((WARNINGS+=1))

        return
    fi


    local previous_root
    local current_root

    previous_root=$(
        find_extracted_backup_root \
            "$previous_dir"
    )

    current_root=$(
        find_extracted_backup_root \
            "$current_dir"
    )


    if [[ -z "$previous_root" ||
          -z "$current_root" ]]; then

        printf '%s\n' \
            'WARNING: Backup comparison structure invalid.' \
            >&2

        ((WARNINGS+=1))

        return
    fi


    local old_manifest="$previous_root/MANIFEST.sha256"
    local new_manifest="$current_root/MANIFEST.sha256"


    if [[ ! -f "$old_manifest" ||
          ! -f "$new_manifest" ]]; then

        printf '%s\n' \
            'WARNING: Manifest missing from comparison backup.' \
            >&2

        ((WARNINGS+=1))

        return
    fi


    local old_paths="$TMP_DIR/old-paths.txt"
    local new_paths="$TMP_DIR/new-paths.txt"

    awk '
      {
        checksum=$1
        sub(/^[^ ]+  /, "")
        print
      }
    ' \
        "$old_manifest" |
    sort \
        > "$old_paths"


    awk '
      {
        checksum=$1
        sub(/^[^ ]+  /, "")
        print
      }
    ' \
        "$new_manifest" |
    sort \
        > "$new_paths"


    local added="$TMP_DIR/added.txt"
    local removed="$TMP_DIR/removed.txt"


    comm \
        -13 \
        "$old_paths" \
        "$new_paths" \
        > "$added"


    comm \
        -23 \
        "$old_paths" \
        "$new_paths" \
        > "$removed"


    local changed="$TMP_DIR/changed.txt"

    : > "$changed"


    while IFS= read -r path; do

        [[ -z "$path" ]] && continue


        local old_file="$previous_root/payload/$path"
        local new_file="$current_root/payload/$path"


        [[ -f "$old_file" &&
           -f "$new_file" ]] ||
        continue


        local old_hash
        local new_hash


        old_hash=$(
            checksum_only \
                "$old_file"
        )

        new_hash=$(
            checksum_only \
                "$new_file"
        )


        if [[ "$old_hash" != "$new_hash" ]]; then

            printf '%s\n' \
                "$path" \
                >> "$changed"
        fi

    done < <(
        comm \
            -12 \
            "$old_paths" \
            "$new_paths"
    )


    local report="$REPORT_DIR/config-changes-$BACKUP_ID.txt"


    {
        printf '%s\n' \
            "=========================================================================="

        printf '%s\n' \
            "                    CONFIGURATION CHANGE REPORT"

        printf '%s\n' \
            "=========================================================================="

        printf '\nPrevious Backup:\n%s\n' \
            "$previous_archive"

        printf '\nCurrent Backup:\n%s\n' \
            "$ARCHIVE"


        printf '\nADDED FILES\n'
        printf '%s\n' \
            "--------------------------------------------------------------------------"

        if [[ -s "$added" ]]; then
            cat "$added"
        else
            printf 'None\n'
        fi


        printf '\nREMOVED FILES\n'
        printf '%s\n' \
            "--------------------------------------------------------------------------"

        if [[ -s "$removed" ]]; then
            cat "$removed"
        else
            printf 'None\n'
        fi


        printf '\nMODIFIED FILES\n'
        printf '%s\n' \
            "--------------------------------------------------------------------------"

        if [[ -s "$changed" ]]; then
            cat "$changed"
        else
            printf 'None\n'
        fi


        if [[ "$DETAILED_DIFF" == true ]]; then

            printf '\nDETAILED DIFF\n'

            printf '%s\n' \
                "--------------------------------------------------------------------------"

            printf '%s\n' \
                "WARNING: The following diff may contain sensitive configuration values."

            diff \
                -ruN \
                "$previous_root/payload" \
                "$current_root/payload" \
                || true
        fi


        printf '\n%s\n' \
            "=========================================================================="

    } > "$report"


    printf 'Change report: %s\n' \
        "$report"
}


apply_retention() {

    (( RETENTION_DAYS > 0 )) || return


    find \
        "$BACKUP_DIR" \
        -maxdepth 1 \
        -type f \
        \( \
            -name 'config-backup-*.tar.gz' \
            -o \
            -name 'config-backup-*.tar.gz.sha256' \
        \) \
        -mtime "+$RETENTION_DAYS" \
        -print \
        > "$TMP_DIR/retention-candidates.txt"


    if [[ ! -s "$TMP_DIR/retention-candidates.txt" ]]; then
        return
    fi


    printf '\nRetention candidates older than %s days:\n' \
        "$RETENTION_DAYS"

    cat \
        "$TMP_DIR/retention-candidates.txt"


    while IFS= read -r old_file; do

        [[ -z "$old_file" ]] && continue

        rm \
            -f \
            -- "$old_file"

    done < "$TMP_DIR/retention-candidates.txt"
}


print_summary() {

    local file_count

    file_count=$(
        find \
            "$PAYLOAD_ROOT" \
            -type f |
        wc -l |
        awk '{$1=$1; print}'
    )


    printf '\n%s\n' \
        "=========================================================================="

    printf '%s\n' \
        "                    CONFIGURATION BACKUP REPORT"

    printf '%s\n' \
        "=========================================================================="

    printf '\n%-24s %s\n' \
        "Backup ID:" "$BACKUP_ID"

    printf '%-24s %s\n' \
        "Archive:" "$ARCHIVE"

    printf '%-24s %s\n' \
        "Checksum File:" "$CHECKSUM_FILE"

    printf '%-24s %s\n' \
        "Configured Sources:" "${#CONFIG_PATHS[@]}"

    printf '%-24s %s\n' \
        "Files Backed Up:" "$file_count"

    printf '%-24s %s\n' \
        "Warnings:" "$WARNINGS"

    printf '%-24s %s\n' \
        "Archive Validation:" "PASSED"

    printf '%-24s %s\n' \
        "Restore Validation:" "PASSED"


    if (( WARNINGS > 0 )); then

        printf '%-24s %s\n' \
            "Overall Status:" \
            "SUCCESS WITH WARNINGS"

    else

        printf '%-24s %s\n' \
            "Overall Status:" \
            "SUCCESS"
    fi


    printf '%s\n' \
        "=========================================================================="
}


run_backup() {

    initialize_backup

    validate_sources

    copy_sources

    create_content_manifest

    create_metadata_manifest

    create_backup_metadata

    create_archive

    verify_archive_readable

    generate_archive_checksum

    verify_archive_checksum


    if ! perform_restore_test \
        "$ARCHIVE"; then

        exit 4
    fi


    create_change_report

    # Retention happens only after successful creation,
    # checksum validation, and restore validation.
    apply_retention

    print_summary


    log_message \
        "INFO" \
        "backup_success archive=$ARCHIVE warnings=$WARNINGS"


    if (( WARNINGS > 0 )); then

        return 1
    fi


    return 0
}


main() {

    parse_arguments "$@"

    set_default_paths

    check_dependencies

    validate_configuration


    TMP_DIR=$(
        mktemp -d
    )


    if [[ -n "$RESTORE_TEST_ARCHIVE" ]]; then

        if perform_restore_test \
            "$RESTORE_TEST_ARCHIVE"; then

            exit 0
        else

            exit 4
        fi
    fi


    run_backup
}


main "$@"
exit $?
```

# 41. What the Production Script Does

The core backup flow is:

```text
Validate
   |
   v
Copy
   |
   v
Manifest
   |
   v
Archive
   |
   v
Checksum
   |
   v
Extract
   |
   v
Verify Restored Files
   |
   v
Compare Previous
   |
   v
Retention
```

Notice:

```text
retention happens last
```

That is intentional.

---

# 42. Why Retention Happens Last

Imagine:

```text
new backup creation fails
```

and your script first deletes:

```text
old backup
```

Now you may have:

```text
no usable backup.
```

Better:

```text
Create new backup
        |
        v
Validate it
        |
        v
Prove restore works
        |
        v
Only then consider deleting old backups
```

---

# 43. Retention Is Destructive

The script uses:

```bash
rm
```

for old backup files.

This is the most destructive operation in the project.

Before deletion it prints:

```text
Retention candidates
```

and limits removal to:

```text
BACKUP_DIR
```

with strict filename patterns.

Never write:

```bash
rm -rf "$BACKUP_DIR"/*
```

for retention.

---

# 44. Safer Production Retention Upgrade

A stronger version should use:

```text
--dry-run
```

for retention.

Example:

```bash
./config-backup.sh \
    --retention-days 30 \
    --dry-run
```

Then show:

```text
Would remove:
config-backup-...
```

without deleting anything.


If you blindly follow all symlinks:


Preserving the link is often safer.


This helps detect configuration relationship changes.

# 91. Common Mistake: Backing Up `/etc` Blindly

# 92. Common Mistake: Backup Inside Source

Suppose you back up:

```text
/opt/veriqta
```

and store archives in:

```text
/opt/veriqta/backups
```

Your next backup may recursively include old backups.

This can create:

```text
backup inside backup inside backup
```

and rapidly consume disk.

Backup destination should be outside backup source paths.
