# Project 17: Certificate Expiration Checker

## Real-World SSL/TLS Monitoring with Bash and OpenSSL

An application can be completely healthy today and become unavailable tomorrow because its TLS certificate expires.

A certificate problem can affect:

* Websites
* APIs
* Load balancers
* Ingress controllers
* Reverse proxies
* Internal services
* Monitoring endpoints
* CI/CD systems

Users may suddenly see:

```text
Your connection is not private
```

or applications may begin reporting:

```text
certificate has expired
```

In this project, we will build:

```text
cert-check.sh
```

The script will connect to a TLS endpoint, retrieve the server certificate, determine when it expires, calculate the number of days remaining, and classify the result.

Example:

```text
==========================================================================
                     TLS CERTIFICATE REPORT
==========================================================================

Host:                   example.com
Port:                   443
Expires:                2026-10-03
Days Remaining:         22
Status:                 WARNING

==========================================================================
```

Our thresholds:

```text
More than 30 days       OK
15-30 days              WARNING
Less than 15 days       CRITICAL
Expired                 CRITICAL
```

The central production lesson is:

```text
Do not wait for users to discover that a certificate expired.

Certificate expiration should be monitored before it becomes an outage.
```

# 4. TLS Basics

TLS protects communication between a client and server.

Conceptually:

```text
Client
   |
   | TLS handshake
   v
Server
   |
   | Certificate
   v
Client verifies identity/trust
   |
   v
Encrypted connection
```

The server certificate contains information such as:

```text
Subject
Issuer
Validity period
Public key
Serial number
Extensions
Subject Alternative Names
```

---

# 5. Certificate Validity Period

A certificate has:

```text
Not Before
Not After
```

For example:

```text
notBefore=Jul  5 00:00:00 2026 GMT
notAfter=Oct  3 23:59:59 2026 GMT
```

Our checker focuses primarily on:

```text
notAfter
```

because that is the expiration time.

---

# 6. Why Certificate Expiration Causes Outages

TLS clients normally expect certificates to be within their validity period.

Once the certificate expires:

```text
server may still be running
network may still work
port 443 may still be open
application may still be healthy
```

but clients can reject the TLS connection.

That creates an important troubleshooting distinction:

```text
TCP works
   |
   v
TLS fails
```

---

# 11. Why `-servername` Matters

Many servers host multiple HTTPS sites behind the same IP address.

Example:

```text
203.0.113.20
   |
   +-- api.example.com
   +-- shop.example.com
   `-- admin.example.com
```

The server may choose which certificate to present based on:

```text
SNI
Server Name Indication
```

So use:

```bash
-servername example.com
```

when checking a hostname.

Otherwise, you may inspect the wrong certificate.

# 19. Date Arithmetic

To calculate:

```text
Days Remaining
```

we need:

```text
Expiration Timestamp - Current Timestamp
```

Conceptually:

```text
expiration_epoch - current_epoch
              |
              v
       seconds remaining
              |
              v
      divide by 86400
              |
              v
         days remaining
```

Because:

```text
1 day = 86,400 seconds
```

# 21. macOS Date Difference

macOS uses BSD `date`.

The equivalent syntax differs.

Example:

```bash
date \
    -j \
    -u \
    -f "%b %e %T %Y %Z" \
    "Oct  3 23:59:59 2026 GMT" \
    +%s
```

This is important because the same script may be run from:

```text
Linux automation server
```

or:

```text
MacBook engineering workstation
```

Our production script will support both.

# 24. Calculate Remaining Seconds

Example:

```bash
SECONDS_REMAINING=$(
    (
        EXPIRY_EPOCH -
        CURRENT_EPOCH
    )
)
```

Correct Bash syntax:

```bash
SECONDS_REMAINING=$((EXPIRY_EPOCH - CURRENT_EPOCH))
```

---

# 25. Calculate Days

Use:

```bash
DAYS_REMAINING=$((SECONDS_REMAINING / 86400))
```

Example:

```text
1900800 seconds
```

becomes:

```text
22 days
```

# 26. Expired Certificate

If:

```text
SECONDS_REMAINING < 0
```

the certificate has already expired.

Example:

# 30. Why CHECK ERROR Is Different From CRITICAL

Suppose:

```text
DNS fails
```

or:

```text
TCP connection times out
```

We cannot honestly say:

```text
certificate expires in <15 days
```

because we never retrieved the certificate.

So report:

```text
CHECK_ERROR
```

rather than pretending the certificate itself is known to be critical.

# 32. Beginner Script

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

HOST="${1:-}"
PORT="${2:-443}"

if [[ -z "$HOST" ]]; then

    printf 'Usage: %s HOST [PORT]\n' \
        "$0" >&2

    exit 3
fi


if ! command -v openssl >/dev/null 2>&1; then

    printf 'ERROR: openssl is required.\n' >&2
    exit 3
fi


END_DATE=$(
    openssl s_client \
        -connect "${HOST}:${PORT}" \
        -servername "$HOST" \
        </dev/null \
        2>/dev/null |
    openssl x509 \
        -noout \
        -enddate
)

if [[ -z "$END_DATE" ]]; then

    printf 'ERROR: Could not retrieve certificate.\n' >&2
    exit 3
fi


END_DATE="${END_DATE#notAfter=}"


if date -d \
    "$END_DATE" \
    +%s \
    >/dev/null 2>&1; then

    EXPIRY_EPOCH=$(
        date -u \
            -d "$END_DATE" \
            +%s
    )

else

    EXPIRY_EPOCH=$(
        date \
            -j \
            -u \
            -f "%b %e %T %Y %Z" \
            "$END_DATE" \
            +%s
    )
fi


CURRENT_EPOCH=$(
    date -u +%s
)


SECONDS_REMAINING=$(
    (
        EXPIRY_EPOCH -
        CURRENT_EPOCH
    )
)


DAYS_REMAINING=$(
    (
        SECONDS_REMAINING /
        86400
    )
)


if (( DAYS_REMAINING > 30 )); then

    STATUS="OK"
    EXIT_CODE=0

elif (( DAYS_REMAINING >= 15 )); then

    STATUS="WARNING"
    EXIT_CODE=1

else

    STATUS="CRITICAL"
    EXIT_CODE=2
fi


EXPIRY_DISPLAY=$(
    date -u \
        -r "$EXPIRY_EPOCH" \
        '+%Y-%m-%d' \
        2>/dev/null ||
    date -u \
        -d "@$EXPIRY_EPOCH" \
        '+%Y-%m-%d'
)


printf '\nHost: %s\n' \
    "$HOST"

printf 'Expires: %s\n' \
    "$EXPIRY_DISPLAY"

printf 'Days Remaining: %s\n' \
    "$DAYS_REMAINING"

printf 'Status: %s\n' \
    "$STATUS"


exit "$EXIT_CODE"
```

# 39. Production Script

```bash
#!/usr/bin/env bash

set -u
set -o pipefail

umask 077

# ------------------------------------------------------------------
# TLS Certificate Expiration Checker
# ------------------------------------------------------------------
#
# Exit codes:
#   0 = all certificates OK
#   1 = one or more WARNING
#   2 = one or more CRITICAL
#   3 = configuration error or certificate check failure
#
# Default thresholds:
#   >30 days      OK
#   15-30 days    WARNING
#   <15 days      CRITICAL
#
# ------------------------------------------------------------------

HOST=""
PORT="443"
INPUT_FILE=""

WARNING_DAYS=30
CRITICAL_DAYS=15

CONNECT_TIMEOUT=10

TOTAL_CHECKED=0
OK_COUNT=0
WARNING_COUNT=0
CRITICAL_COUNT=0
ERROR_COUNT=0

OVERALL_STATUS="OK"

TIMEOUT_COMMAND=""

SCRIPT_DIR=$(
    cd -- "$(dirname -- "${BASH_SOURCE[0]}")" &&
    pwd
)

readonly SCRIPT_DIR

LOG_DIR="$SCRIPT_DIR/logs"
LOG_FILE="$LOG_DIR/certificate-check.log"

TMP_DIR=""


show_help() {

    cat <<EOF
Usage:

  $0 HOST

  $0 \
    --host HOST \
    [--port PORT]

  $0 \
    --file endpoints.csv

Options:

  --host HOST
      TLS hostname to check.

  --port PORT
      TLS port.
      Default: 443

  --file FILE
      CSV inventory containing:
      host,port

  --warning-days N
      Warning threshold.
      Default: 30

  --critical-days N
      Critical threshold.
      Default: 15

  --timeout N
      Connection deadline in seconds where supported.
      Default: 10

  --help
      Display help.

Threshold policy:

  More than WARNING_DAYS:
      OK

  CRITICAL_DAYS through WARNING_DAYS:
      WARNING

  Less than CRITICAL_DAYS:
      CRITICAL

Examples:

  $0 example.com

  $0 \
    --host example.com \
    --port 443

  $0 \
    --file endpoints.csv

  $0 \
    --host example.com \
    --warning-days 45 \

}


cleanup() {

    if [[ -n "${TMP_DIR:-}" &&
          -d "$TMP_DIR" ]]; then

        rm -rf -- "$TMP_DIR"
    fi
}


trap cleanup EXIT INT TERM


is_positive_integer() {

    [[ "$1" =~ ^[0-9]+$ ]] &&
    (( $1 > 0 ))
}


validate_port() {

    local port="$1"

    [[ "$port" =~ ^[0-9]+$ ]] || return 1

    (( port >= 1 && port <= 65535 ))
}


parse_arguments() {

    local -a positional=()

    while [[ $# -gt 0 ]]; do

        case "$1" in

            --host)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --host requires a value.\n' >&2
                    exit 3
                }

                HOST="$2"
                shift 2
                ;;

            --port)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --port requires a value.\n' >&2
                    exit 3
                }

                PORT="$2"
                shift 2
                ;;

            --file)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --file requires a value.\n' >&2
                    exit 3
                }

                INPUT_FILE="$2"
                shift 2
                ;;

            --warning-days)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --warning-days requires a value.\n' >&2
                    exit 3
                }

                WARNING_DAYS="$2"
                shift 2
                ;;

            --critical-days)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --critical-days requires a value.\n' >&2
                    exit 3
                }

                CRITICAL_DAYS="$2"
                shift 2
                ;;

            --timeout)

                [[ $# -ge 2 ]] || {
                    printf 'ERROR: --timeout requires a value.\n' >&2
                    exit 3
                }

                CONNECT_TIMEOUT="$2"
                shift 2
                ;;

            --help|-h)

                show_help
                exit 0
                ;;

            --*)

                printf 'ERROR: Unknown option: %s\n' \
                    "$1" >&2

                exit 3
                ;;

            *)

                positional+=("$1")
                shift
                ;;
        esac
    done


    if (( ${#positional[@]} > 1 )); then

        printf 'ERROR: Too many positional arguments.\n' >&2
        exit 3
    fi


    if (( ${#positional[@]} == 1 )); then

        if [[ -n "$HOST" ]]; then

            printf 'ERROR: Specify host once.\n' >&2
            exit 3
        fi

        HOST="${positional[0]}"
    fi
}

detect_timeout_command() {

    if command -v timeout >/dev/null 2>&1; then

        TIMEOUT_COMMAND="timeout"

    elif command -v gtimeout >/dev/null 2>&1; then

        # Common when GNU coreutils is installed on macOS.
        TIMEOUT_COMMAND="gtimeout"

    else

        TIMEOUT_COMMAND=""
    fi
}


validate_configuration() {

    if [[ -n "$HOST" &&
          -n "$INPUT_FILE" ]]; then

        printf '%s\n' \
            'ERROR: Use either --host or --file, not both.' \
            >&2

        exit 3
    fi


    if [[ -z "$HOST" &&
          -z "$INPUT_FILE" ]]; then

        printf 'ERROR: A host or input file is required.\n' >&2
        exit 3
    fi


    if ! validate_port "$PORT"; then

        printf 'ERROR: Invalid port: %s\n' \
            "$PORT" >&2

        exit 3
    fi


    if ! is_positive_integer "$WARNING_DAYS"; then

        printf 'ERROR: Invalid warning threshold.\n' >&2
        exit 3
    fi


    if ! is_positive_integer "$CRITICAL_DAYS"; then

        printf 'ERROR: Invalid critical threshold.\n' >&2
        exit 3
    fi


    if (( CRITICAL_DAYS > WARNING_DAYS )); then

        printf '%s\n' \
            'ERROR: Critical threshold cannot exceed warning threshold.' \
            >&2

        exit 3
    fi


    if ! is_positive_integer "$CONNECT_TIMEOUT"; then

        printf 'ERROR: Invalid timeout.\n' >&2
        exit 3
    fi


    if [[ -n "$INPUT_FILE" ]]; then

        if [[ ! -f "$INPUT_FILE" ]]; then

            printf 'ERROR: File not found: %s\n' \
                "$INPUT_FILE" >&2

            exit 3
        fi


        if [[ ! -r "$INPUT_FILE" ]]; then

            printf 'ERROR: File not readable: %s\n' \
                "$INPUT_FILE" >&2

            exit 3
        fi
    fi
}


log_message() {

    local level="$1"
    local message="$2"

    mkdir -p "$LOG_DIR"

    printf '[%s] [%s] %s\n' \
        "$(date '+%Y-%m-%d %H:%M:%S')" \
        "$level" \
        "$message" \
        >> "$LOG_FILE"
}


convert_certificate_date_to_epoch() {

    local certificate_date="$1"

    local epoch


    # GNU date: common on Linux.
    if epoch=$(
        date \
            -u \
            -d "$certificate_date" \
            +%s \
            2>/dev/null
    ); then

        printf '%s\n' \
            "$epoch"

        return 0
    fi


    # BSD date: macOS.
    if epoch=$(
        date \
            -j \
            -u \
            -f "%b %e %T %Y %Z" \
            "$certificate_date" \
            +%s \
            2>/dev/null
    ); then

        printf '%s\n' \
            "$epoch"

        return 0
    fi


    return 1
}


format_epoch_date() {

    local epoch="$1"

    local formatted


    # BSD/macOS.
    if formatted=$(
        date \
            -u \
            -r "$epoch" \
            '+%Y-%m-%d' \
            2>/dev/null
    ); then

        printf '%s\n' \
            "$formatted"

        return 0
    fi


    # GNU/Linux.
    if formatted=$(
        date \
            -u \
            -d "@$epoch" \
            '+%Y-%m-%d' \
            2>/dev/null
    ); then

        printf '%s\n' \
            "$formatted"

        return 0
    fi


    return 1
}


retrieve_certificate() {

    local host="$1"
    local port="$2"
    local certificate_file="$3"
    local error_file="$4"

    local output_file="$TMP_DIR/sclient-${TOTAL_CHECKED}.out"
    local status


    if [[ -n "$TIMEOUT_COMMAND" ]]; then

        "$TIMEOUT_COMMAND" \
            "$CONNECT_TIMEOUT" \
            openssl s_client \
                -connect "${host}:${port}" \
                -servername "$host" \
                -showcerts \
                </dev/null \
                >"$output_file" \
                2>"$error_file"

        status=$?

    else

        openssl s_client \
            -connect "${host}:${port}" \
            -servername "$host" \
            -showcerts \
            </dev/null \
            >"$output_file" \
            2>"$error_file"

        status=$?
    fi


    if (( status != 0 )); then
        return 1
    fi


    awk '
      /-----BEGIN CERTIFICATE-----/ {
        capture=1
      }

      capture {
        print
      }

      /-----END CERTIFICATE-----/ {
        exit
      }
    ' \
        "$output_file" \
        > "$certificate_file"


    if [[ ! -s "$certificate_file" ]]; then
        return 1
    fi


    if ! openssl x509 \
        -in "$certificate_file" \
        -noout \
        >/dev/null 2>&1; then

        return 1
    fi


    return 0
}


get_certificate_metadata() {

    local certificate_file="$1"

    openssl x509 \
        -in "$certificate_file" \
        -noout \
        -enddate \
        -subject \
        -issuer \
        -serial
}


classify_days() {

    local days="$1"

    if (( days > WARNING_DAYS )); then

        printf 'OK'

    elif (( days >= CRITICAL_DAYS )); then

        printf 'WARNING'

    else

        printf 'CRITICAL'
    fi
}


increase_overall_status() {

    local status="$1"

    case "$status" in

        CRITICAL)

            OVERALL_STATUS="CRITICAL"
            ;;

        WARNING)

            if [[ "$OVERALL_STATUS" != "CRITICAL" ]]; then
                OVERALL_STATUS="WARNING"
            fi
            ;;

        CHECK_ERROR)

            # Preserve CRITICAL if an actual expiration problem
            # has already been detected.
            if [[ "$OVERALL_STATUS" == "OK" ]]; then
                OVERALL_STATUS="CHECK_ERROR"
            fi
            ;;
    esac
}


check_certificate() {

    local host="$1"
    local port="$2"

    local certificate_file
    local error_file

    local metadata
    local raw_end_date
    local certificate_date

    local expiry_epoch
    local current_epoch
    local seconds_remaining
    local days_remaining
    local expiry_display

    local subject
    local issuer
    local serial

    local status


    ((TOTAL_CHECKED+=1))


    certificate_file="$TMP_DIR/certificate-${TOTAL_CHECKED}.pem"
    error_file="$TMP_DIR/error-${TOTAL_CHECKED}.log"


    if ! retrieve_certificate \
        "$host" \
        "$port" \
        "$certificate_file" \
        "$error_file"; then

        status="CHECK_ERROR"

        ((ERROR_COUNT+=1))

        increase_overall_status "$status"


        printf '%-30s %-7s %-12s %-8s %s\n' \
            "$host" \
            "$port" \
            "ERROR" \
            "-" \
            "$status"


        log_message \
            "ERROR" \
            "host=$host port=$port status=$status certificate_retrieval_failed"

        return
    fi


    metadata=$(
        get_certificate_metadata \
            "$certificate_file"
    )


    raw_end_date=$(
        openssl x509 \
            -in "$certificate_file" \
            -noout \
            -enddate
    )


    certificate_date="${raw_end_date#notAfter=}"


    if ! expiry_epoch=$(
        convert_certificate_date_to_epoch \
            "$certificate_date"
    ); then

        status="CHECK_ERROR"

        ((ERROR_COUNT+=1))

        increase_overall_status "$status"


        printf '%-30s %-7s %-12s %-8s %s\n' \
            "$host" \
            "$port" \
            "ERROR" \
            "-" \
            "$status"


        log_message \
            "ERROR" \
            "host=$host port=$port status=$status expiration_date_parse_failed"

        return
    fi


    current_epoch=$(
        date -u +%s
    )


    seconds_remaining=$(
        (
            expiry_epoch -
            current_epoch
        )
    )


    # Use floor-like behavior for positive values.
    if (( seconds_remaining >= 0 )); then

        days_remaining=$(
            (
                seconds_remaining /
                86400
            )
        )

    else

        # Keep expired certificates clearly below zero.
        days_remaining=$(
            (
                -1 *
                (
                    ((-seconds_remaining) + 86399) /
                    86400
                )
            )
        )
    fi


    expiry_display=$(
        format_epoch_date "$expiry_epoch"
    )


    status=$(
        classify_days \
            "$days_remaining"
    )


    subject=$(
        printf '%s\n' "$metadata" |
        awk -F= '
          /^subject=/ {
            sub(/^subject=/, "")
            print
          }
        '
    )


    issuer=$(
        printf '%s\n' "$metadata" |
        awk '
          /^issuer=/ {
            sub(/^issuer=/, "")
            print
          }
        '
    )


    serial=$(
        printf '%s\n' "$metadata" |
        awk -F= '
          /^serial=/ {
            print $2
          }
        '
    )


    case "$status" in

        OK)
            ((OK_COUNT+=1))
            ;;

        WARNING)
            ((WARNING_COUNT+=1))
            ;;

        CRITICAL)
            ((CRITICAL_COUNT+=1))
            ;;
    esac


    increase_overall_status "$status"


    printf '%-30s %-7s %-12s %-8s %s\n' \
        "$host" \
        "$port" \
        "$expiry_display" \
        "$days_remaining" \
        "$status"


    log_message \
        "INFO" \
        "host=$host port=$port expires=$expiry_display days_remaining=$days_remaining status=$status serial=${serial:-unknown}"


    if [[ "$status" != "OK" ]]; then

        printf '  Subject: %s\n' \
            "${subject:-unknown}"

        printf '  Issuer:  %s\n' \
            "${issuer:-unknown}"
    fi
}


process_single_host() {

    check_certificate \
        "$HOST" \
        "$PORT"
}


process_file() {

    local host
    local port
    local line_number=0


    while IFS=',' read -r host port ||
          [[ -n "$host" || -n "$port" ]]; do

        ((line_number+=1))


        host="${host#"${host%%[![:space:]]*}"}"
        host="${host%"${host##*[![:space:]]}"}"

        port="${port#"${port%%[![:space:]]*}"}"
        port="${port%"${port##*[![:space:]]}"}"


        [[ -z "$host" && -z "$port" ]] && continue


        if (( line_number == 1 )) &&
           [[ "$host" == "host" &&
              "$port" == "port" ]]; then

            continue
        fi


        [[ "$host" =~ ^# ]] && continue


        if [[ -z "$host" ]]; then

            printf 'ERROR: Missing host on line %s.\n' \
                "$line_number" >&2

            exit 3
        fi


        if [[ -z "$port" ]]; then
            port="443"
        fi


        if ! validate_port "$port"; then

            printf 'ERROR: Invalid port on line %s: %s\n' \
                "$line_number" \
                "$port" >&2

            exit 3
        fi


        check_certificate \
            "$host" \
            "$port"

    done < "$INPUT_FILE"
}


print_header() {

    printf '%s\n' \
        "=========================================================================="

    printf '%s\n' \
        "                     TLS CERTIFICATE REPORT"

    printf '%s\n' \
        "=========================================================================="

    printf '\n%-30s %-7s %-12s %-8s %s\n' \
        "HOST" \
        "PORT" \
        "EXPIRES" \
        "DAYS" \
        "STATUS"

    printf '%s\n' \
        "--------------------------------------------------------------------------"
}


print_summary() {

    printf '\n%s\n' \
        "--------------------------------------------------------------------------"

    printf '%-28s %s\n' \
        "Total Checked:" "$TOTAL_CHECKED"

    printf '%-28s %s\n' \
        "OK:" "$OK_COUNT"

    printf '%-28s %s\n' \
        "Warning:" "$WARNING_COUNT"

    printf '%-28s %s\n' \
        "Critical:" "$CRITICAL_COUNT"

    printf '%-28s %s\n' \
        "Check Errors:" "$ERROR_COUNT"

    printf '\n%-28s %s\n' \
        "Overall Status:" "$OVERALL_STATUS"

    printf '%s\n' \
        "=========================================================================="
}


return_status() {

    if (( CRITICAL_COUNT > 0 )); then
        return 2
    fi


    if (( WARNING_COUNT > 0 )); then
        return 1
    fi


    if (( ERROR_COUNT > 0 )); then
        return 3
    fi


    return 0
}


main() {

    parse_arguments "$@"

    check_dependencies

    detect_timeout_command

    validate_configuration


    TMP_DIR=$(
        mktemp -d
    )


    print_header


    if [[ -n "$INPUT_FILE" ]]; then

    print_summary

}


main "$@"
exit $?
```

# 100. `timeout` on macOS

GNU:

```text
timeout
```

is commonly available on Linux.

It is not provided by default on many macOS installations.

Users who install GNU coreutils on macOS may instead have:

```text

```

Our script detects both.

If neither exists, the OpenSSL connection still runs, but the external hard deadline is unavailable.

# 148. Production Mindset

A weak certificate process says:

```text
We renew certificates when someone notices they are about to expire.
```

A stronger process says:

```text
Every production TLS endpoint is inventoried.

Expiration is checked automatically.

More than 30 days is healthy.

15-30 days generates a warning.

Less than 15 days is critical.

Renewal is verified against the certificate actually served to clients.
```

That is operationally reliable.
