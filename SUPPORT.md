# Support

DEVOPS-WORLD is a public educational repository maintained on a best-effort basis.

## Choose the right channel

| Need | Where to go |
|---|---|
| Incorrect command, broken lab, or documentation problem | Open a bug report |
| Focused suggestion for repository content | Open a feature request |
| Small correction with a clear fix | Open a pull request |
| Security vulnerability or exposed secret | Follow `SECURITY.md`, never post publicly |
| General discussion about a learning topic | Use GitHub Discussions if enabled |

## Before asking for help

1. Search existing issues and discussions.
2. Read the relevant prerequisites and troubleshooting section.
3. Confirm that you are using the documented versions and environment.
4. Collect the exact command, complete error message, and relevant logs.
5. Remove secrets, personal data, account IDs, and private infrastructure details.

## What to include

- The document or lab you are following
- Your goal and the step that failed
- Operating system and version
- Tool versions
- Exact command or configuration, with secrets removed
- Complete error output in a code block
- What you expected to happen
- What you already tried

Screenshots are useful for visual problems, but paste searchable text for commands and errors whenever possible.

## Support boundaries

The project cannot provide:

- Emergency support for production systems
- Access to private cloud accounts or infrastructure
- Help using leaked exam material
- Guaranteed response times
- Personalized job placement or certification guarantees
- Debugging based only on an image with no reproducible details

For a production incident, follow your organization's incident process and contact the responsible provider or support team.
